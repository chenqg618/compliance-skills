# 差旅费标准与报销核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：差旅费报销与标准表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

本版本执行 **6 项**（跑 `--sample` 会打印实际执行了哪些）：

1. **报销合计勾稽**：住宿费 + 交通费 + 伙食补助 + 其他费用 = 报销合计
2. **超标金额勾稽**：实际金额 − 标准上限 = 超标金额（正数=超标），逐项相加复核
3. **合计行逐列复核**：合计行的每一列 = 各明细行相加
4. **同一人同一行程重复行检测**：同一人 + 同一行程 + 同一日期出现两行
5. **空白与占位符检测**：姓名 / 行程 / 报销合计为空或写「待填」「无」「—」
6. **金额为负检测**：住宿费、交通费、伙食补助、其他费用、报销合计、超标金额为负

**本版本不包含**（引擎如实列出，不会用默认值编造）：

- 住宿费超标准提示（含超出金额）
- 交通费超标准提示（含超出金额）
- 伙食补助按天数 × 标准勾稽
- 出差天数与起止日期不一致检测
- 超标但无审批标记提示

## 常见错法（这张表里真的会有人这么填）

1. **住宿费只给一列「住宿费标准」，不区分"实际"与"上限"**：实际金额与标准上限必须是两列——
   合成一列后引擎会认不出"标准上限"这一列（或把标准当实际），要么给不出结论，要么**静默算错**。
2. **报销合计漏加「其他费用」**：合计 = 住宿 + 交通 + 伙食补助 + **其他费用**；漏一项就会被报"报销合计勾稽不符"，
   而且金额差恰好等于被漏掉的那一项。
3. **超标金额填成「实际 − 标准」的负数**：未超标的行请填 0；填负数会被当成"超标金额与（实际−上限）不符"，
   而正确的口径是"超了就填超出额、各超标项相加"。
4. **同一人同一行程拆成两行（去程 / 返程、或两次出差）却不写清日期**：会被报"同一人同一行程出现多行"；
   请在行程或日期里区分，例如「北京-上海（去程）」。
5. **报销合计留空或写「待定」**：合计是必需列，空着这条单子整行都核不了；同时"合计行"要写「合计」两个字，
   否则那一行会被当成一张普通报销单参与核对。
