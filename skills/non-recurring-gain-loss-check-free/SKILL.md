# 非经常性损益与扣非净利润核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**上市公司/拟上市公司的财务与证券事务**，在**年报/半年报披露、以及审计与券商核查之前**。
非经常性损益要**逐项列示、扣除所得税影响、并区分归属母公司与少数股东**：

- 扣除所得税影响后金额 = 本期金额 − 涉及所得税影响；
- 归属母公司 + 归属少数股东 = 扣除所得税影响后金额；
- 类别与"是否非经常性"必须一致；每个非经常性项目都要写说明。

## 这个免费版查什么

1. **合计行逐列复核**（本期/上期金额/所得税影响/扣除后/归属母公司/归属少数股东）；
2. **扣除所得税影响后金额 = 本期金额 − 所得税影响**（P0）；
3. **归属母公司 + 归属少数股东 = 扣除后金额**（P0）；
4. **类别与"是否非经常性"口径矛盾**（P1）；
5. **说明为空或占位符**（非经常性项目必须逐项说明，P1）；
6. **项目+类别重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论并报「列缺失」）。

## 常见错法（这些表里真的会有人这么填）

1. **忘了扣所得税影响**：政府补助等要按适用税率扣税后再列示，直接填本期金额会让扣非净利润偏高。
2. **归属母公司/少数股东不拆**：把全部金额挂在母公司会让少数股东损益错配，合并层面勾稽也对不上。
3. **把"经常性"的政府补助也列进去**：与日常经营密切相关的补助属于经常性，口径判错会影响扣非指标。
4. **同类项目分多行却不写类别**：会报重复行；请按"项目 + 类别"对齐口径。
5. **说明写"其他"**：非经常性项目要写清性质与金额构成，否则审计与监管都会追问。

## 边界（请务必知道）

- **不做**判断：某项目**是否属于**非经常性损益，请按证监会口径与公司会计政策认定；
- **不代替**审计程序或出具鉴证意见，也不判断扣非指标的披露口径；
- **不核对**凭证、批文、合同的**真伪**，也不与账务系统逐行比对；
- **不读取**财务系统 / 公告底稿的原始文件——需要你先导出成文本贴进来；
- **不判断**相关事项的税务处理与企业所得税影响（属于税务判断）。
