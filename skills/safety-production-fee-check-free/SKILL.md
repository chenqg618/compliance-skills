# 安全生产费用提取与使用核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：矿山、建筑施工、危险化学品、交通运输等企业的**安全管理部门 + 财务**，
在**每月结账 / 提取安全费用 / 专户报销列支**这些固定节点上必须把这张表核一遍才能往下走。
安全生产费用要按营业收入（或产量）规定的比例提取、**专户核算、专款专用**；
提取不足和挪用都是监管检查与处罚的高发项。

**这张表会逐项核对什么**：安全生产费用提取与使用核对表的逐行算术（应提取金额、余额滚动）、
合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

1. **应提取金额复算** —— `计提基数 × 提取比例 = 应提取金额`（营业收入口径或产量口径，取表里填的那个基数）；
2. **期末余额滚动复算** —— `期初余额 + 本期提取 − 本期使用 = 期末余额`；
3. **合计行逐列复核** —— 合计行每一列都要等于明细行相加；
4. **同一核算主体同一期间重复行检测**；
5. **空白与占位符检测**（「待填」「—」这类占位符会静默跳过检查）；
6. **金额或比例为负检测**。

- 本期没有使用也要写 `0.00`，留空会被当成占位符报出来。

## 常见错法（这张表里真的会有人这么填）

1. **计提基数用了含税收入（或不含税收入）却没统一口径**：比例是套在**不含税营业收入**上的，
   表里却直接抄了含税销售额（增值税专用发票的价税合计），基数被抬高 13%/9%，
   应提取金额看着"提够了"，实际按监管口径仍然不足；反过来用净额口径又可能多提。
   同一张表里**不同月份、不同项目必须用同一个口径**，并在表头/备注里写清是含税还是不含税。
2. **产量口径与营业收入口径混用**：矿山按吨（元/吨）提取，却把当月营业收入填进了基数列；
   或者同一专户里几个月按产量、几个月按收入，比例列一会儿写 `2%` 一会儿写 `15元/吨`。
   口径一混，应提取金额的复算就对不上，余额滚动会把错误带到后面每一期。
3. **把非安全生产支出挤进专户**：安全培训之外的普通劳保、日常保洁、甚至招待费、罚款
   记进"本期使用"，看着余额没超，其实是**挪用**；本期使用一旦超过
   「期初余额 + 本期提取」，期末余额就会变成负数（监管检查最容易抓的一项）。
4. **跨年结转未体现**：上年结余没有结转进本期「期初余额」，或者上年末的期末余额与
   本年初的期初余额对不上。表现是使用率异常（明明没提多少却花了很多），
   或者余额在年度切换处凭空跳变 —— 专户流水一比就露。
5. **提取比例还按旧行业标准**：办法与地方标准改过之后，表里仍按几年前的比例提取
   （比如建筑施工还用 1.00%，而现在要求不低于 1.50%）。行业类别也要如实填，
   「危险化学品」「矿山」「建筑施工」「交通运输」适用不同下限，填错行业类别等于用错标准。
