# 工程产值与进度确认核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：项目经理 / 商务 / 财务在**每月末报产值、请甲方（监理、造价）确认之前** ——
「工程产值与进度确认表」经甲方签认后就是**工程结算与收入确认的依据**，签完再改要走变更流程。

**这张表会逐项核对什么**：本期计量金额复算、累计计量与合同额闭合、合计行、重复行、空缺与负数。
每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（6 项）

1. **计量金额复算**：本期计量金额 = 本期已完产值 − 本期扣款
2. **累计计量与剩余产值勾稽**：累计计量 + 剩余产值 = 合同额
3. **合计行逐列复核**：合计行的本期已完产值、计量、扣款、应付 = 各明细行之和
4. **同一项目同一期重复行检测**
5. **空白与占位符检测**（`—`、`待填`、`无`、`N/A` 都算没填）
6. **金额或产值为负检测**

## 常见错法（这张表里真的会有人这么填）

1. **本期计量金额直接抄本期已完产值**：漏了本期扣款（质保金、预付款抵扣、代扣水电、违约扣款）。
   只要本期有扣款，`计量 = 已完产值` 这一行就一定不成立。
2. **累计列只累加产值，忘记再减一次累计扣款**：累计计量 = 累计已完产值 − **累计**扣款；
   只累加产值的话，差额会逐期滚大（第 3 期就差了 3 期的扣款）。
3. **剩余产值用「合同额 − 累计已完产值」倒算**：本表口径是 剩余产值 = 合同额 − **累计计量**，
   两者相差的正好是累计扣款；用错基数会同时带出累计勾稽不符。
4. **同一项目同一期拆成两行填**（月内两批报量各占一行）却都不合并：会被判重复行，
   且累计列容易被重复汇总；月内分批请在备注里说明，本期汇总成一行。
5. **用「—」「待填」「无」「N/A」代替 0.00，把冲回直接写成负数行**：
   占位符一律按"没填"处理（该是 0 就写 0.00）；负数金额会被单独挑出来要求说明来源。


## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 已完产值超过合同额检测
- 形象进度与产值偏差超 10 个百分点提示（参考口径）
- 计量金额超过已完产值检测
- 扣款比例偏离参考区间（0%~10%）提示（参考口径）
- 累计计量与累计产值不一致提示（偏差超 10%，参考口径）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。
