# 加工贸易手册与保税料件核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：关务 / 单证 / 财务岗位在**每月关务结账**与**每本手册核销前**，
必须把这张表核一遍才能往下走 —— 对不上，手册核销不了：要补税、缴缓税利息，重的还有行政处罚。

**这张表会逐项核对什么**：
· 理论耗用 = 出口成品数量 × 单耗
· 期末结存 = 期初结存 + 进口料件 − 理论耗用 − 余料结转 − 内销补税数量
· 合计行逐列复核（单耗是比率，不参与加总）
· 同一手册号、同一料件、同一期间的重复行
· 空白与占位符、数量或金额为负

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

1. 理论耗用复算（出口成品数量 × 单耗 = 理论耗用数量）
2. 期末结存滚动复算（期初结存 + 进口料件 − 理论耗用 − 余料结转 − 内销补税数量 = 期末结存）
3. 合计行逐列复核
4. 同一手册号同一料件同一期间重复行检测
5. 空白与占位符检测
6. 数量或金额为负检测

（检查项由引擎的 `CHECKS_GIVEN` 导出，跑 `--sample` 会打印实际执行了哪些；
本版本不包含的 5 项列在 `CHECKS_WITHHELD` 里，不做也不假装做。）

## 常见错法（这张表里真的会有人这么填）

1. **单耗含损耗与净耗混用**：本表要填的是**备案单耗**（每单位出口成品的保税料件耗用量，含损耗）。
   有人填净耗、有人另填一套"净耗 + 损耗"口径 ⇒ 理论耗用整体差一个损耗率；
   同一本手册同一料件的单耗口径必须与手册备案逐字一致。
2. **单位不统一（千克 / 个 / 米）**：同一本手册里进口按千克、出口按个、结转按米，
   数量直接加减没有意义。一行一个料件只允许一个单位；换单位要先把数量换算成同一单位再填。
3. **余料结转跨手册未体现**：把 A 手册的余料结转到 B 手册，本表只在 B 手册记了"余料结转"、
   A 手册没记转出 ⇒ 两本手册同时不平衡。余料结转要在**转出、转入两边**都体现。
4. **内销未及时补税**：内销（含边角料、残次品内销）用了保税料件却不在核销前补税，
   "内销补税数量"这一列长期填 0、进口数却对不上；补税要在手册核销前完成并在这张表体现。
5. **手册展期后新旧备案数混算**：手册展期 / 变更后同一料件有两套备案数（旧手册余数 + 新备案数），
   有人把两套加在一列里填，"备案数量"会突然变大。展期后按**新手册号单独一行**，别把新旧备案数相加。


## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。
