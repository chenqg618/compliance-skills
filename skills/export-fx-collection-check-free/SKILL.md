# 出口报关与收汇核销核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：出口报关与收汇核销表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（6 项）

1. **应收外汇勾稽**：报关金额 × (1 − 佣金率) 必须等于表里的应收外汇；
2. **核销差额勾稽**：应收外汇 − 已收汇 必须等于表里的核销差额；
3. **合计行逐列复核**：报关金额 / 应收外汇 / 已收汇 / 核销差额四列的合计 = 各行之和；
4. **同一报关单号重复行检测**：一票只能一行，重复会让收汇与退税被重复计算；
5. **空白与占位符检测**：报关单号 / 所属期 / 报关金额 / 佣金率 / 应收外汇 / 已收汇 / 核销差额；
6. **金额为负检测**：报关金额、应收外汇、已收汇出现负数请单独列示冲回。

另有 5 项不在本版本执行（见引擎导出的 `CHECKS_WITHHELD`，跑 `--sample` 会如实列出），
**不会用默认值编造结论**。

## 常见错法（本表这 5 种写法真的会被填错）

1. **佣金率那格填「扣佣金额」而不是比率**：报关 100000、付佣 2000，却在佣金率列写 `2000`。
   本工具把大于 1 的数当百分数（2000 → 2000%），应收外汇会算成负数并命中应收外汇勾稽。
   要么写 `2%`，要么写 `0.02`。
2. **应收外汇照抄报关金额（漏扣佣金）**：报关 100000、佣金率 2%，应收外汇写 `100000.00`；
   正解是 `98000.00`。写错会命中勾稽，而且核销差额跟着错。
3. **核销差额写成「已收汇 − 应收外汇」（符号反了）**：应收 98000、已收 90000，差额写 `-8000.00`；
   本工具口径固定是「应收外汇 − 已收汇 = 8000.00」，符号反了当场命中核销差额勾稽。
4. **合计行把「汇率」「佣金率」也相加**：把 7.10 + 7.05 + 6.95 写成 `21.10`。
   这两列不是可加量，本工具只复核报关金额 / 应收外汇 / 已收汇 / 核销差额；费率列求和会误导下一手核对。
5. **一票多笔收汇就拆成多行、报关单号重复**：EXP-001 分两笔各占一行。
   本工具按报关单号判重复并命中；正确做法是**一票一行**，把几笔收汇加总填进「已收汇」。
