# 预提费用与待摊费用摊销核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**总账会计**，在**月度结账与费用归属期核对之前**：

- 期末未摊余额 = 期初未摊余额 − 本期实摊金额；
- 累计已摊金额 + 期末未摊余额 = 总金额；
- 本期实摊 ≤ 期初未摊余额；直线法每期 = 总金额 ÷ 受益月数。

## 这个免费版查什么

1. **合计行逐列复核**（总金额/期初未摊/本期应摊/本期实摊/累计已摊/期末未摊）；
2. **期末未摊 = 期初未摊 − 本期实摊**（P0）；
3. **累计已摊 + 期末未摊 = 总金额**（P0）；
4. **本期实摊为负**（P0）；
5. **本期实摊 > 期初未摊余额**（超摊，P1）；
6. **费用项目+受益起始月重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论）。

## 常见错法（这些表里真的会有人这么填）

1. **期初未摊余额按"总金额 − 累计已摊"倒填**：它必须与上期期末一致（滚动来源），倒填会让滚动关系永远自洽但掩盖真实差错。
2. **预提费用的依据留空**：预提是要有依据的（合同、上年同期、用量估计），留空无法复核，也会被审计追问。
3. **待摊与预提混在一张表却不写类型**：两者的期初来源不同（待摊是已付未摊、预提是未付已提），混填会让口径无法复核。
4. **受益月数填"已过月数"**：受益月数是**总期数**（如 12 个月），不是已摊月数；填错会让直线法校验与后续期数全偏。
5. **同一项目分两次建行**（跨年重新建）：会报重复行；跨年请沿用同一项目名并把受益期连续写明。
