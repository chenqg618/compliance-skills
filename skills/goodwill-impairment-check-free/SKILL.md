# 商誉减值测试底稿核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**有并购商誉的公司（含上市公司/拟上市）**，在**每年年度减值测试
与给审计交底稿之前**，必须把这几列核一遍：

- 资产组账面价值 = 商誉账面价值 + 可辨认净资产账面价值；
- 减值损失 = max(0, 资产组账面价值 − 可收回金额)；
- 商誉减值 ≤ 商誉账面价值（先冲商誉，不能超冲）；本期商誉净额 = 商誉账面价值 − 商誉减值。

审计第一个翻的就是这几列能不能对上；而这类错误**全都能算出来对错**。

## 这个免费版查什么

1. **合计行逐列复核**（商誉 / 可辨认净资产 / 账面价值 / 可收回金额 / 减值损失 / 商誉减值 / 商誉净额）；
2. **资产组账面价值 = 商誉 + 可辨认净资产**；
3. **减值损失 = max(0, 账面价值 − 可收回金额)**（最常错的一条）；
4. **商誉减值 ≤ 商誉账面价值**（超冲商誉是审计必抓的错）；
5. **本期商誉净额 = 商誉账面价值 − 商誉减值**；
6. **同一资产组重复行**检测；
7. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这些表里真的会有人这么填）

1. **可收回金额填成"评估值 − 账面价值"**：可收回金额是**资产组整体**能收回的钱，不是差额；填错会让减值公式整条错。
2. **只改了商誉减值、忘了改本期商誉净额**：本工具第 5 条专门抓它（商誉净额 = 商誉 − 商誉减值）。
3. **减值损失填商誉减值之外的差额**：减值先冲商誉、再按比例分摊到其他资产；如果只冲了商誉，两列会不等。
4. **同一资产组写两行**（不同估值方法各贴一遍）：会报重复行；如确要并列两种方法，请另建资产组或在方法里注明。
5. **把测试方法写成"评估"两个字**：口径太模糊，完整档会提示按收益法/市场法/公允价值减处置费用写清。


## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；

· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 减值损失小于商誉减值（先冲商誉的顺序错了）检测
- 本期商誉净额为负检测
- 可收回金额为负检测
- 账面价值 > 可收回金额却未计提减值（漏提）检测
- 减值测试方法不在常见口径（收益法/市场法/公允价值减处置费用等）提示

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

- **不做**会计判断：资产组怎么划分、商誉怎么分摊、可收回金额该用现金流折现还是公允价值减处置费用
  ——这些要与审计/评估沟通，本工具只核你给的表内数字与勾稽关系；
- **不核对**折现率、增长率、可比公司等估值假设是否合理；**不出具**减值测试的审计或鉴证意见；
- **不读取**评估报告 / 财务系统 / 估值模型的原始文件——需要你先导出成文本贴进来；
- **不判断**商誉减值在税法上能否税前扣除（属于税务判断）；
- 材料不足（认不出表头、没有数据行、必需列缺失）时**不给结论**，只告诉你还缺什么。
