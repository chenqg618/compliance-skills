# 广告文案违规体检（免费版）

> **完全本地运行**：引擎已打包在本技能里（`scripts/engine/`）。
> 不联网、不需要 API Key、**没有调用次数上限**，你的文案不出本机。

## 什么时候用

**谁会在什么时候用**：电商运营、品牌市场部、信息流投手每天要出十几条标题／主图文案／口播稿／详情页，
发布前想先过一遍机器能判的表述风险。踩一次绝对化用语或疗效承诺，代价是下架、限流、罚款，
**这是直接损失，不是"品牌调性"问题**。

**它做什么**：把一段广告文案按行扫一遍，把违规点**逐条标出来** —— 每条给**原文行号**、
命中的**原词**、以及**一句法条依据**，第三方拿同一份原文就能复算。

一句话定位：**发布前的"错别字检查"，只不过查的是法条层面的错。**

## 这个免费版查什么

引擎会跑下面 6 项（`--sample` 会打印实际执行了哪些）：

| # | 检查项 | 主要依据 | 级别 |
|---|---|---|---|
| ① | 绝对化用语（含《广告绝对化用语执法指南》豁免判定） | 《广告法》第九条第三项 | P0 |
| ② | 医疗／药品／医美违禁表述（疗效、根治、无副作用等） | 《广告法》第十六条、第十七条 | P0 |
| ③ | 教育培训保证性承诺（保过、包就业、提分 X 分等） | 《广告法》第二十四条第一项 | P0 |
| ④ | 投资理财／房地产承诺（保本、稳赚、升值回报等） | 《广告法》第二十五条、第二十六条 | P0 |
| ⑤ | 虚假广告类保证性承诺（100% 有效、3 天见效等） | 《广告法》第四条、第二十八条 | P0 |
| ⑥ | 缺失必要提示（保健食品未标「本品不能代替药物」等） | 《广告法》第十八条第二款等 | P2 |

**结论只有三种**：

- `ERROR_FOUND` —— 有 P0/P1 命中（必须改）；
- `NEEDS_REVIEW` —— 只有 P2（多为"漏了必要提示"，需人工补齐）；
- `NO_ISSUE_FOUND` —— 0 命中（**只有清理过的干净文案才会得到这个结论**）。

**它故意不报的东西也会列出来**：`exempted` 里是**按《执法指南》判定可豁免、因此没报成问题**的表述
（「最新款」「100% 羊毛」「一站式服务」「最后一步」这类），每条都写明豁免依据。
这是精准度，也是可审计性 —— 你能看见机器放过了什么、凭什么放过。

## 怎么用

```bash
node scripts/run.mjs --sample                      # 先看样例（一段合规文案，0 命中）
node scripts/run.mjs --input my-copy.json          # 跑自己的文案
node scripts/run.mjs --input my-copy.json --json   # 机器可读输出
```

入参就是一段文案，**一行一句最清晰**（报出来的行号就对着你自己的原文）：

```json

```

也可以直接把文案存成纯文本文件用 `--input` 读入（不是合法 JSON 时按纯文本处理）。

## 常见错法

做广告文案体检时，人和工具都容易犯下面这 5 个错 —— 每一个都会让"体检"变成新的风险源：

1. **见到「最」字就一刀切删掉。** 「最新款」「最近上新」「最后一步」「尽最大努力」都是时间顺序词或服务态度表述，
   《指南》第二条、第五条明确不算绝对化用语；「100% 羊毛」「100% 纯棉」是客观成分标示，也不该删。
   一刀切会把能用的卖点改废，还让人不再信这个工具 —— **本工具把这些登记进 `exempted` 并写明依据，而不是报成问题**。
2. **只换词、不换承诺。** 把「最好」改成「特别好」「超好用」，对效果的绝对断言一点没变，
   平台和监管看的是**承诺本身**，不是那个字。正确做法是换成可举证的具体描述（具体参数、检测结论、报告编号）。
3. **「销量第一」不写限定条件与来源。** 这类写法的合法路径只有一条：**限定具体时间／地域 + 确有事实依据**
   （例如「2024 年上半年华东区销量第一」并附第三方数据来源），依《指南》第六条第（六）项主张不适用；
   依第七条，**无法证明真实性的仍会被查处**。缺时间、缺来源，就是一条 P0。
4. **拿行业禁语讲卖点，以为换个说法就没事。** 医疗／药品／医美的「根治、无副作用、治愈率」，
   教育培训的「保过、包就业、提分 X 分」，投资理财的「保本、稳赚、无风险」，
   是三条各自独立的法条硬红线（②③④ 三项），换词不换承诺照样命中。
5. **保健食品漏掉必要提示，或把功效写成疗效。** 保健食品广告必须显著标明「本品不能代替药物」，
   漏掉就是形式违规（⑥，P2，最容易被抓）；把「增强免疫力」写成「降血糖」「治好失眠」，
   就从功效断言变成了疾病治疗功能（②，P0）。

另外一条通用提醒：**体检通过 ≠ 审核通过**。本工具只做机械可判定的表述比对，
平台细则、行业审批口径、画面与价格标示都不在其中（见下）。

## 边界（请务必知道）

- 本工具**不做** `OUT_OF_SCOPE` 里列的判断：不判断广告整体是否违法、不替代法务与监管口径、
  不核查文案事实是否真实、不判断画面／代言人／价格标示、不做跨句语境推断、不覆盖特殊行业审批与境外法律。
- **材料不足时不给结论**：`text` 为空、只有空白、只有一个字符或类型不对时，
  返回 `insufficient_input` 并列出缺什么，**既不认定"违规"也不认定"合规"**，更不会输出「未发现问题」。
- 每个命中项都需要**人工复核**：反讽、引用法规原文、竞品评测的正当引用都可能被机械命中。
- 本报告不构成法律意见；是否违法由市场监督管理部门结合广告整体语境、事实依据与社会危害程度依法认定。

## 可复算

引擎是纯 Node 标准库实现，**没有大模型、不联网**（源码里没有 `fetch`／`http`／`https`／`net`／`dns`／`tls`），
也不 require 本技能包以外的任何文件。同一份文案跑两次，`findings`／`exempted`／`summary` **逐字一致**；
每条结论都带 `line`／`col`／`term`／`basis`，你可以照着原文一行一行数回去。
