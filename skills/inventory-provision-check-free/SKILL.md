# 存货跌价准备核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：存货跌价准备计提表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

1. **应计提跌价准备复算**：`存货成本 − 可变现净值 = 应计提`（**小于 0 取 0** —— 孰低，不确认升值），逐项复核。
2. **准备余额勾稽**：`期初准备余额 + 本期计提 − 本期转回或结转 = 期末准备余额`，逐项复核。
3. **合计行逐列复核**：存货成本 / 可变现净值 / 应计提跌价准备 / 期初准备余额 / 本期计提 / 本期转回或结转 / 期末准备余额，合计必须等于明细**逐列**之和。
4. **同一存货（同期间）重复行检测**：同一期间、同一存货出现两行 ⇒ 跌价准备会被重复计提。
5. **空白与占位符检测**：存货名称 / 存货成本 / 可变现净值 / 应计提跌价准备 / 期初准备余额 / 本期计提 / 期末准备余额，缺一项就核不了。
6. **金额为负检测**：存货成本、可变现净值、应计提、本期计提、本期转回或结转出现负数时逐条列出（红字与冲回请分列成正数）。

**本版本不包含**（如实列出，见 `scope.checks_not_run`）：
可变现净值高于成本却仍计提/保留跌价准备检测、本期计提额超过应计提额检测、准备余额为负检测、
本期转回超过期初余额提示、跌价率偏离参考区间（0%~50%）提示。

## 常见错法（这张表里真的会有人这么填）

1. **可变现净值直接填售价**：可变现净值 = 估计售价 − 至完工时估计将发生的成本 − 估计销售费用 − 相关税费。只填售价会把跌价准备**提少**，而这张表的内部勾稽看不出这个口径错 —— 取值依据只能靠你自己确认。
2. **计提与转回挤在同一列**：把转回写成负数塞进「本期计提」，余额勾稽的方向就反了。计提额与转回/结转额应当**分列**（本工具按 `期初 + 本期计提 − 本期转回或结转` 复算），冲回单独列示并在表里注明。
3. **合计行的应计提按"成本合计 − 可变现净值合计"倒算**：应计提是**逐项孰低后**的金额，有 0 下限时"合计差额"与"逐项之和"本来就不相等；本工具按逐列求和复核，差多少就报多少。
4. **期初余额抄了上期期末，却漏了本期结转**：存货销售时会同时结转已计提的跌价准备，漏填「本期转回或结转」会让期末余额虚高，差额往往正好等于结转额。
5. **同一存货在明细里出现两行**（一行按类别、一行按品名，或把上期行留在表里）：两套口径混在一张表里，跌价准备会被重复计提，而合计行看起来还是"对"的。
