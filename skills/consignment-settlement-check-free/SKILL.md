# 寄售代销结算核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**；材料不出本机。

## 什么时候用

**谁会在什么时候用**：零售 / 制造 / 品牌方**每月和代销方（商场专柜、电商代运营）对账时必做**。
货是放在别人柜台上卖的，卖了多少、还剩多少、该扣多少手续费、该结多少钱，
全都由代销方给的清单说了算 —— 而那张清单每个月都在几个地方悄悄漏钱。

**这张表会逐项核对什么**：
- 寄售结存 = 上期结存 + 本期发货 − 本期已销 − 退货数量
- 应结金额 = 代销方已销金额 − 代销手续费
- 代销手续费 = 代销方已销金额 × 手续费率
- 发货数量 = 寄售结存 − 期初结存 + 本期已销 + 退货
- 合计行逐列复核（每一列的合计是否等于各行之和）
- 重复清单号检测；关键字段空缺 / 占位符 / 负值 / 日期倒挂检测

每条结论都带**原文行号与出处**，可被第三方用同一份输入复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张台账里真的会有人这么填）

1. **期初结存照抄上期已销**。上期已销是"卖掉的"，期初结存是"还没卖的"；
   填反了以后 结存 = 期初 + 发货 − 已销 会算出双倍已销量，整列结存都不对。
2. **退货只冲了数量没冲金额**。退货栏填了件数，应结金额却还是按全部已销金额算的；
   代销方卖剩的货退回来了，钱却照样结给它 —— 退货那一笔金额必须同时从应结金额里扣回。
3. **已结金额填成"应结金额"**。已结金额是**本期实际收到的钱**（银行到账或代销方已确认结款），
   不是"应该收的钱"；两列填成一样，已销未结就永远看不见。
4. **手续费率填成合同费率**。台账上填的是本月**实际计提**的费率：
   特批促销活动、分品类扣点不同时会高于合同费率，照抄合同费率就查不出多扣。
5. **总账寄售库存直接等于本期发货**。这一列是**总账（或进销存系统）里的寄售库存余额**，
   它是拿来和 期初 + 发货 − 已销 − 退货 复算比对的；直接填发货数，结存永远"对得上"，差异被藏起来。
6. **代销方实盘结存照抄总账数**。这一列要填**代销方盘点回传的实际结存**；
   照抄总账等于自己跟自己核，代销方少货、货已卖未记已销全都发现不了。
7. **单据日期填成对账完成日期**。单据日期是发货 / 销售发生的日期，用来推算挂账月数；
   填成对账那天，挂账半年也会显示成 0 个月。
8. **一个商品编码开两行、清单号却写成一个**。多批次发货分行列示是对的，
   但清单号必须逐行唯一；两行同号会让"重复清单号"失效，也可能被重复结一次。
