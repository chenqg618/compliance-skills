# 出口退税申报单证一致性核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：出口退税申报单证一致性核对表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. **差额列用了别的口径**：把运费、保费、佣金算进去（FOB 与 CIF 混着用），
   或者拿美元金额去减人民币金额。同一票货必须**同一个币别、同一个价格术语**，
   差额才只是尾差；口径一混，差额列看起来"有值"，其实两张单证根本没法比。
2. **应退税额没按「计税金额 × 退税率」算**：拿报关金额当计税金额（退税的计税依据是
   购进/计税金额，不是报关金额），或者退税率跟着商品编码走却填了上一版文库的税率 ——
   算多了要追回，算少了是自己的钱没拿回来。
3. **合计行手打或从别处粘贴**：明细改了合计行没跟着改，或者加总时漏掉了红字冲回行。
   申报表的取数口径就是这张表的合计行，合计对不上，报上去的表与附送单证就对不上。
4. **同一报关单号、同一所属期、同一发票号粘了两行**：重复的那一行把报关金额、应退税额
   与收汇都重复计一遍，退税额当场虚增。多品项的报关单应当按不同发票号分行登记。
5. **关键格留空或写「待填」，数量金额带负号**：空值与占位符会让对应的复算**静默跳过**
   （看起来核过了，其实那一列根本没参与）；红字冲回与退货应单独列示并在备注里说明。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 报关金额与发票金额不符超容差提示（两张单证本身对不上，超过尾差容差才报）
- 收汇金额与报关金额不符提示
- 退税率与商品编码适用税率不一致提示
- 进项发票金额不足（小于应退税额对应进项）提示
- 同一报关单重复申报提示（同一报关单号横跨两个所属期）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。
