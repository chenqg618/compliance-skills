# 在产品与完工产品成本分配核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**制造企业的成本会计**，在**月度成本结账与产成品入库之前**：

- 本期投入合计 = 材料 + 人工 + 制造费用；
- 完工产品成本 + 期末在产品成本 = 期初在产品成本 + 本期投入合计（成本守恒）；
- 分配方法（约当产量法 / 定额比例法 / 在产品按定额成本计算 / 不计算在产品成本）要写清并前后一致。

## 这个免费版查什么

1. **合计行逐列复核**（期初 / 材料 / 人工 / 制造费用 / 投入合计 / 完工数量 / 在产品数量 / 完工成本 / 期末在产品成本）；
2. **本期投入合计 = 材料 + 人工 + 制造费用**（P0）；
3. **成本守恒：完工产品成本 + 期末在产品成本 = 期初 + 本期投入**（P0）；
4. **完工成本或期末在产品成本为负**（P0）；
5. **数量缺失或为零**时明确报「数量缺失/为零」（不给分配结论）；
6. **产品+工序重复行**检测；
7. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这些表里真的会有人这么填）

1. **把"本期投入合计"当成"完工产品成本"**：本期投入还要加上期初在产品、减去期末在产品，直接相等会让成本守恒永远差一笔。
2. **在产品数量填了但期末在产品成本填 0**：完整档会点出来（漏留在产品），这也是成本被"做低"的常见手法。
3. **约当产量按"数量"直接折半**：约当产量要看**完工程度**（材料一次投入还是在产品约当），凭感觉折半会让分配结果偏。
4. **不同车间用不同方法却不写方法**：跨期无法复核口径，完整档会提示按常见四法写清。
5. **同一产品按批次拆多行、工序名不一致**：会报重复行；请统一"产品+工序"口径或按批次单独建表。


## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 分配方法不在常见口径（约当产量法 / 定额比例法 / 在产品按定额成本计算 / 不计算在产品成本）提示
- 单位完工成本 = 完工产品成本 ÷ 完工数量，与其所在工序平均值偏离超过 30% 提示
- 在产品数量 > 0 但期末在产品成本为 0（漏留在产品）检测
- 完工数量 > 期初数量 + 本期投入数量（数量口径缺失）提示
- 期初在产品成本占本期投入合计比例超过 50% 提示（期初异常大）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 边界（请务必知道）

- **不做**会计判断：在产品完工程度、定额是否合理、该用哪种分配方法，请按成本核算制度与准则判断；
- **不代替**成本审计程序或出具鉴证意见；
- **不核对**领料单、工时记录、费用凭证的**真伪**，也不与 MES/ERP 逐行比对；
- **不读取** MES / ERP / 财务系统的导出文件——需要你先导出成文本贴进来；
- **不判断**成本核算结果的税务影响（属于税务判断）。
