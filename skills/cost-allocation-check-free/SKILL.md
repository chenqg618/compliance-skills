# 在产品与完工产品成本分配核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**制造企业的成本会计**，在**月度成本结账与产成品入库之前**：

- 本期投入合计 = 材料 + 人工 + 制造费用；
- 完工产品成本 + 期末在产品成本 = 期初在产品成本 + 本期投入合计（成本守恒）；
- 分配方法（约当产量法 / 定额比例法 / 在产品按定额成本计算 / 不计算在产品成本）要写清并前后一致。

## 这个免费版查什么

1. **合计行逐列复核**（期初 / 材料 / 人工 / 制造费用 / 投入合计 / 完工数量 / 在产品数量 / 完工成本 / 期末在产品成本）；
2. **本期投入合计 = 材料 + 人工 + 制造费用**（P0）；
3. **成本守恒：完工产品成本 + 期末在产品成本 = 期初 + 本期投入**（P0）；
4. **完工成本或期末在产品成本为负**（P0）；
5. **数量缺失或为零**时明确报「数量缺失/为零」（不给分配结论）；
6. **产品+工序重复行**检测；
7. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这些表里真的会有人这么填）

1. **把"本期投入合计"当成"完工产品成本"**：本期投入还要加上期初在产品、减去期末在产品，直接相等会让成本守恒永远差一笔。
2. **在产品数量填了但期末在产品成本填 0**：完整档会点出来（漏留在产品），这也是成本被"做低"的常见手法。
3. **约当产量按"数量"直接折半**：约当产量要看**完工程度**（材料一次投入还是在产品约当），凭感觉折半会让分配结果偏。
4. **不同车间用不同方法却不写方法**：跨期无法复核口径，完整档会提示按常见四法写清。
5. **同一产品按批次拆多行、工序名不一致**：会报重复行；请统一"产品+工序"口径或按批次单独建表。
