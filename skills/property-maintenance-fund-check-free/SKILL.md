# 物业专项维修资金使用与分摊核对（免费版）

> **核对过程在本机运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：物业公司的项目经理 / 财务，以及**业委会**的财务委员 ——
在**每年公示维修资金收支之前**，以及**每一次动用维修资金之后**，都必须把
「归集台账 − 使用台账 − 分摊明细 − 银行余额」核对清楚，才敢公示、才敢入账。

**为什么必须核**：住宅专项维修资金是**业主共有**的钱。动用要满足"双三分之二"表决、要公示、
要按**建筑面积分摊到户**，还要与首期归集额、历年使用额、利息收入、专户余额逐项对上。
**算错就是业主投诉、审计与监管问题** —— 业主问"为什么我家交这么多"、街道与审计要求整改，
往往就是分摊基数、参与面积或余额勾稽错了一处。这些表都能手算复现 ⇒ 可以机械核对。

**这张表会逐项核对什么**（免费版 6 项，逐条可复算）：

1. **归集勾稽**：期初余额 + 本期归集 + 利息收入 − 本期使用 = 期末余额（逐行复算，差额不为零即列出）
2. **分摊勾稽**：该户分摊额 = 使用总额 × 该户建筑面积 ÷ 参与分摊建筑面积（逐户，分币容差 0.01）
3. **分摊明细合计**：同一项目 Σ分摊额 = 使用总额（逐项目复核）
4. **重复分摊**：同一期间内 同一户 + 同一项目 出现两次即点名
5. **表决比例**：同意面积 ÷ 参与面积 ≥ 规定比例（不达标即报出实际比例与差额）
6. **空白与格式**：必需列缺失 ⇒ 材料不足、不给结论；关键单元格空白 / 占位符、金额认不出或为负、业主证件号未脱敏逐行点名

每条结论都带**原文行号 + 原文行内容 + 数字**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么 —— 既不输出「一致」，也不输出「未发现问题」。

## 这个免费版查什么 / 不查什么

本版本**只执行**上面 6 项；跑 `--sample` 会打印本次实际执行的检查项。
引擎里的 `CHECKS_WITHHELD` **如实列出本版本不执行**的检查项 —— 分摊到户后余额不为负与单户超归集额点名、
各家银行账户利息口径核对、同一项目跨期重复动用、表决资料与使用金额的对应性、
分楼栋×分项目汇总整改清单。它们只是「未执行的检查项」的说明文本，**不是实现**，本包也拿不到这些结论。

```bash

```

## 使用次数与完整档

本免费版会在**本包目录**里记一个使用次数（`scripts/.hint-count`，一个整数，不含任何机器或用户信息）。

· 前 3 次：**完全离线**（不发生任何网络请求），输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 第 4 次起才会向服务端问一次（只发包标识与次数），拿回完整档说明；
· 请求不可用（离线 / 超时 / 被拦截）时什么都不做，**核对结果与退出码不受任何影响**；
· 不想要这次统计可以加 `--no-stats`（核对功能完全不受影响，只是拿不到完整档说明）。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。


## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 分摊到户后余额不为负 + 单户累计使用超过其归集额的部分点名
- 利息收入按各家银行账户口径核对（多个账户利息合计 vs 入账利息）
- 同一项目在多个期间重复动用（跨期重复）检测
- 表决资料与使用金额的对应性（同一项目多次表决、金额不一致）检测
- 分楼栋×分项目的汇总清单（按差额排序，给出可整改动作 consolidated_actions）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 常见错法（维修资金台账里最常见的 5 个）

1. **分摊分母用错**：分母必须是"参与分摊的建筑面积"，用小区总面积会把每户分摊额算小。
2. **表决比例按户数算**：法规口径是**面积**（双三分之二），按户数算会得出错误结论。
3. **把归集额与余额混为一列**：期初余额 + 归集 + 利息 − 使用 = 期末余额，缺一项就断链。
4. **同一项目多次动用不合并**：分期动用同一项目时，重复分摊很难靠肉眼发现。
5. **利息收入漏记**：多个银行账户的结息要合计入账，否则余额永远差一点。

口径说明：工具只核**台账与分摊表的算术与勾稽**，不判断表决程序是否合法、也不替代审计；
材料不足时**不给结论**。
