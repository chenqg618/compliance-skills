# 中标结果与合同一致性核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：中标通知书与合同草案的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. **只贴合同、不贴中标通知书那一列**：对照表要左右两栏都有值，只有一边就是"不可比"，本工具会明说不可比，**不会当成一致**。
2. **金额写成"约 128 万"**：金额要素按数值比较，带"约/万/元"的模糊写法解析不出数字，那一行就白对了。
3. **把合同里的"详见附件"当成一致**：`详见/另行约定/待定` 这类表述在完整档里会被单独报出来 —— 它不能当"一致"。
4. **中标价没变但工期/质量悄悄改了**：只盯金额是常见漏法。工期、质量标准、付款方式都属于实质性内容，逐行都要对。
5. **要素名用词不一**（一处写"中标价"、一处写"合同价"）：工具会按要素名找行，名字对不上就当成缺要素。建议两边统一用行业通用名。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 签订时限检测（中标通知书发出后 30 日内订立合同）
- 金额差异超过容忍比例检测（实质性偏离）
- 实质性条款偏离词表扫描（延长/下调/免除/放弃等）
- 不可核对表述检测（详见/另行约定/待定 等不能当"一致"）
- 单侧缺失检测（一侧有值、另一侧为空 => 不可比）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。
