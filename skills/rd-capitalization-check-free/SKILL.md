# 研发支出资本化与费用化划分核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**有研发投入的企业（尤其高新与拟上市）**，在**每月归集研发支出、
以及年度汇算与审计之前**：

- 本期发生额 = 资本化金额 + 费用化金额；
- 期末无形资产余额 = 累计资本化金额 − 累计摊销额；
- 本期摊销额 ≈ 累计资本化金额 ÷ 摊销月数（直线法，偏离超 5% 提示）。

研究阶段应费用化、开发阶段才可能资本化——**审计与税务都会盯着这几列**，而它们全都能算出来对错。

## 这个免费版查什么

1. **合计行逐列复核**（发生额 / 资本化 / 费用化 / 累计资本化 / 累计摊销 / 本期摊销 / 期末余额）；
2. **本期发生额 = 资本化金额 + 费用化金额**（最常错的一条）；
3. **期末无形资产余额 = 累计资本化金额 − 累计摊销额**；
4. **资本化金额或费用化金额为负**检测；
5. **本期摊销额为负**检测；
6. **同一项目同一阶段重复行**检测；
7. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这些底稿里真的会有人这么填）

1. **把研究阶段的支出也填进"资本化金额"**：研究阶段必须费用化；完整档会直接点出来。
2. **发生额只填资本化那部分**：本期发生额是**全部**研发支出，资本化 + 费用化必须等于它，否则第 2 条就红。
3. **累计资本化按"本期资本化"重复填**：累计是滚动值（上期累计 + 本期资本化），填错会让期末余额整列错。
4. **摊销月数填 0 却又有本期摊销额**：摊销月数是摊销期限，0 会让直线法校验跳过、也可能暴露口径混乱。
5. **同一项目分阶段各贴一行却写同一个阶段名**：会报重复行；不同阶段请如实写"研究阶段/开发阶段"。

## 边界（请务必知道）

- **不做**会计判断：研发阶段怎么划分、某笔支出**该不该资本化**需专业论证并与审计确认；
- **不判断**研发费用加计扣除的归集口径与优惠资格（见同系列「研发费用加计扣除归集核对」）；
- **不代替**审计程序、不出具鉴证意见，也不判断资本化时点是否恰当；
- **不读取**研发项目管理系统 / 工时系统 / 财务系统的导出文件——需要你先导出成文本贴进来；
- **不判断**无形资产摊销年限是否合理（只核你给的摊销月数与摊销额之间的算术关系）；
- 材料不足（认不出表头、没有数据行、必需列缺失）时**不给结论**，只告诉你还缺什么。
