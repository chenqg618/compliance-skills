# 车队油耗与运费核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：车辆油耗与运费台账的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

1. **定额油耗复算**：行驶里程 ÷ 100 × 百公里油耗定额 = 定额油耗
2. **油耗差异复算**：油卡加油量 − 定额油耗 = 油耗差异
3. **合计行逐列复核**（比率列与单价列不参与加总）
4. **同一车牌同一月份重复行检测**
5. **空白与占位符检测**
6. **数量或金额为负检测**

完整档追加的检查项见 `CHECKS_WITHHELD`；跑 `--sample` 会打印本次实际执行了哪些。

## 常见错法（这张台账真的会填错的写法）

1. **把「百公里油耗定额」和「定额油耗」当成同一列。** 前者是 L/100km 的比率，后者是「里程 ÷ 100 × 定额」算出来的总升数。别名表里若把「油耗定额」排在「百公里油耗定额」前面，这一整列会被抢走 —— 不报缺列、不报错，只是从此静默算错。
2. **里程为 0 时直接算「加油量 ÷ 里程 × 100」。** 会得到 Infinity / NaN，把整张表的百公里油耗都判成异常；必须先挡住里程 ≤ 0 再算。
3. **把「油耗差异」当成金额列去做「为负」检查。** 差异 = 加油量 − 定额油耗，本来就可正可负：负数是省油，不是异常。算进去，省油的车全会被报。
4. **合计行把「百公里油耗定额」「油品单价」也相加。** 比率与单价不可加总，加起来当然对不上各行之和，于是天天报「合计不符」。
5. **里程单位「公里 / 万公里」混填。** 同一个月里 5000 和 5 混着写，定额油耗整列会错 1000 倍 —— 看着像偷油，其实是单位问题。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 单车油耗超定额比例超过参考上限（10%）提示（参考口径）
- 单车收入低于成本（油费金额 + 过路费）提示
- 油卡加油量与油卡充值额不一致检测（充值额 vs 加油量 × 油品单价）
- 里程为零却有油耗检测
- 百公里油耗偏离参考区间（20~50L/100km）提示（参考口径）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。
