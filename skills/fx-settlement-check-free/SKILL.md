# 外币结算与汇兑损益核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：有外币业务的企业，**每笔收付都要按两个汇率过一遍** ——
记账本位币 = 外币金额 × 记账汇率；结算本位币 = 外币金额 × 结算汇率；汇兑损益 = 二者之差。
汇率用错、日期串了、损益方向反了，都会进损益表；月结时几十上百笔，人眼核不动。

**这张表会逐项核对什么**：
· 记账本位币 = 外币金额 × 记账汇率；结算本位币 = 外币金额 × 结算汇率
· 汇兑损益 = 结算本位币 − 记账本位币（**方向最容易写反**）
· 已收本位币应与结算本位币一致；合计行逐列复核；重复单据与空缺检测

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. 请补上这些再跑；材料不足时本工具不做任何认定，也不套用默认值。
2. 记账汇率是确认收入/应收时的汇率；用成结算日汇率会让汇兑损益凭空消失。
3. 结算汇率应取**实际收款日**的汇率；两个汇率取同日就等于没有汇兑损益。
4. 方向最容易写反：**结算汇率高于记账汇率 ⇒ 收益（正）**；表里符号错了会让损益表反向。
5. 已收 = 结算（同一笔款）；不一致通常是银行扣了电报费/手续费，或汇率取错 —— 请查明后单列。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 汇率为非正检测
- 外币金额非正检测
- 汇兑损益与「已收本位币 − 记账本位币」口径不符检测
- 汇兑损益绝对额超过记账本位币 10% 的异常波动检测
- 已收本位币为负检测

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。
