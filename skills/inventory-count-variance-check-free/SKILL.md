# 存货盘点差异与账实调整核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**制造/零售/物流企业的存货会计与仓管**，在**月度/年度盘点、以及账实调整入账之前**：

- 差异数量 = 实盘数量 − 账面数量；差异金额 = 实盘金额 − 账面金额；
- 账面金额 = 账面数量 × 账面前单价；实盘金额 = 实盘数量 × 盘点单价；
- 有差异就必须写清差异原因（盘盈/盘亏都要有依据）。

## 这个免费版查什么

1. **合计行逐列复核**（账面数量/账面金额/实盘数量/实盘金额/差异数量/差异金额）；
2. **差异数量 = 实盘 − 账面**（P0）；
3. **差异金额 = 实盘 − 账面**（P0）；
4. **账面金额 = 账面数量 × 账面前单价**（P1）；
5. **实盘金额 = 实盘数量 × 盘点单价**（P1）；
6. **仓库+存货编码重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论并报「列缺失」）。

## 常见错法（这些表里真的会有人这么填）

1. **账面数量填成"账面结存"而不是盘点基准日的账**：盘点基准日与账面日期不一致时差异全是假的；先锁定基准日再导账。
2. **单价用含税价或最新采购价**：账面金额要用**账面单价**（一般为不含税成本），实盘金额用**盘点单价**，两者混用会让差异金额失真。
3. **同一存货在两个仓库各建一行但仓库列为空**：会报重复行；请写清仓库维度。
4. **差异原因填"正常损耗"却没有任何依据**：完整档会要求写明责任与处理；"正常损耗"也需要定额或历史数据支撑。
5. **盘盈不写原因**：盘盈同样要说明（漏记入库、退货未入账等），否则无法判断是不是账务差错。


## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 差异金额为正（盘盈）但差异原因空白提示
- 差异金额为负（盘亏）但差异原因空白提示
- 差异金额绝对值超过账面金额 30%（重大差异）提示
- 实盘数量为负（实盘数填错）检测
- 差异原因为「未查明 / 待查 / 不详」提示（要求写清责任与处理）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 边界（请务必知道）

- **不做**会计判断：盘盈盘亏该计入管理费用还是营业外、是否属于前期差错，请按准则判断；
- **不代替**盘点程序或出具鉴证意见，也不判断存货跌价准备；
- **不核对**盘点表签字、出入库单的**真伪**，也不与 WMS/ERP 逐行比对；
- **不读取** WMS / ERP / 财务系统的导出文件——需要你先导出成文本贴进来；
- **不判断**盘亏的增值税进项转出与所得税影响（属于税务判断）。
