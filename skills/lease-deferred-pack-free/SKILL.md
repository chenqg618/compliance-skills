# 租赁与递延收益技能包（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`scripts/engine/`）。
> 不联网、不需要 API Key、**没有调用次数上限**、**不写任何文件**，材料不出本机。

## 什么时候用

**有租赁与政府补助的总账会计**，在**每月摊销与年度汇算之前**。

典型场景：月度/季度复核前，把一类检查一次跑完所有合同

## 这个免费版查什么

**一次跑完所有合同，每家合同一行结论**（免费版的核心产出，完整可用）：

1. **租赁负债与使用权资产核对** —— 复用 `parts/lease-liability-check/`（逐字节来自免费包 `lease-liability-check-free`）
2. **政府补助递延收益核对** —— 复用 `parts/gov-subsidy-deferred-income-check/`（逐字节来自免费包 `gov-subsidy-deferred-income-check-free`）

> 每一项的实际规则在 `scripts/engine/parts/<检查项>/` 里（**逐字节复用**仓库里已有的免费引擎，
> 一行规则都没有改）。本包只做"目录 → 合同 → 逐项派发"的编排。

## 怎么用

```bash
node scripts/run.mjs --sample                 # 单合同样例（内置，2 项全跑）
node scripts/run.mjs --sample-batch           # 3 家合同的批量样例（干净 / 有硬伤 / 未交材料）
node scripts/run.mjs --input <合同目录>     # 批量：每个子目录 = 一家合同
node scripts/run.mjs --input <材料.json>        # 单合同：JSON 或纯文本
```

合同目录怎么放（每个子目录里放这家合同的一套材料，每项用 `=== 检查项 ===` 分段，Tab 分隔最稳）：

```
合同目录/
  豫州总部租赁合同（2026-04 摊销）/租赁与递延材料.txt
  中岳产业园补助文件（2026-04 结转）/租赁与递延材料.txt
```

## 结论怎么读

- 每家合同一行：`[结论] 合同名｜问题 N 项（P0/P1/P2）｜每一项:通过 / 有问题(n) / 未执行`；
- 有价值的是**问题明细**：每条都带 `合同 + 检查项 + 来源文件:行号 + 类别 + 具体数字`；
- 「未执行」与「通过」是两件事：**没交材料 / 材料认不出表 = 未执行**，不是"没问题"。

## 常见错法

- **把几份合同的材料放进同一个子目录**：`--input` 指向的目录里，**每个子目录 = 一份合同**。混在一起时结论里就没有合同名，跨合同台账也分不出是谁。
- **期初余额与上期期末对不上**：租赁负债表要能与上期衔接，衔接不上时逐期相加校验会直接报出来。
- **把递延收益的结转额当成补助总额**：结转额只是本期分摊的那一部分，要核"已结转 + 余额 = 总额"，混填会被合计校验抓出来。
- **租赁期数与摊销期数混用**：期数决定每期摊销额，用错会让整列数字系统性偏移。
- **拿 `--sample` 的输出当自己的结论**：样例数字是虚构的，必须换成你自己的材料再跑。
