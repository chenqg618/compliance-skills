# 建筑工程材料用量与损耗核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**、材料不出本机。

## 什么时候用

**谁在什么时候用**：项目物资员 / 施工员 / 预算员 / 成本会计在**每个分部分项完工、每月物资盘点与成本归集、
限额领料考核结算之前** —— 「材料需用计划与实际消耗对照表」是材料成本、超耗扣款与物资台账的原始依据，
签完再改就要走签证 / 变更流程。

**这张表会逐项核对什么**（免费版执行 6 类，逐条都带**原文行号**）：

1. **损耗量复算** —— 损耗量 = 领用量 − 实际消耗量，差 0.01 也会报。
2. **损耗率复算** —— 损耗率 = 损耗量 ÷ 领用量 × 100%，分母是**领用量**。
3. **损耗率与参考上限比对** —— 用表内「损耗率上限」列；表里没有这一列时按参考上限 5.00% 提示。
4. **需用计划量与实际消耗量差异** —— 实耗量超过需用计划量时报出超出多少、超出几个百分点。
5. **合计行逐列复核** —— 合计行的需用计划量 / 领用量 / 实际消耗量 / 损耗量 = 各明细行之和。
6. **重复材料行与关键字段空缺** —— 同一分部分项 + 同一期间 + 同一材料 + 同一规格出现两次以上；
   必需列为空或写着「待填 / 待补 / — / N/A」。

每条结论都带**原文行号与算式**，可被第三方用同一份输入复算；
材料不足时**不给结论**，会明确列出还缺什么，也不会用默认值编出结论。

## 这个免费版查什么

上面 6 类就是本版本执行的全部检查项。跑 `--sample` 会在 `scope.checks` 里打印本次实际执行了哪些，
`scope.checks_not_run` 会如实列出**本版本没有执行**的检查项（只列出，不会伪造结论）。

## 怎么用

```bash
node scripts/run.mjs --sample                      # 先看样例（样例本身就是一张自洽的对照表）
node scripts/run.mjs --input 你的材料.json          # 跑自己的材料
node scripts/run.mjs --input 你的材料.json --json   # 机器可读输出
```

入参两种写法都行：

- `{"text": "（把表的**表头**和若干行一起复制进来，Tab 分隔最稳）"}`
- 直接把「材料需用计划与实际消耗对照表」（**含表头**）从 Excel 复制成文本贴进 `.json` 里；
  文件不是合法 JSON 时整体按纯文本材料处理。

必需列（缺一列就不给结论）：分部分项工程、期间、材料名称、需用计划量、领用量、实际消耗量、损耗量、损耗率。
可选列：规格型号、单位、损耗率上限、单价、备注（不填也能跑；损耗率上限缺失时退化成参考上限 5.00%）。

## 出参

- `status`：`success` 才有结论；`insufficient_input` 表示材料不足，此时**没有** `result`、**没有** `findings`，
  只有 `missing`（缺什么）与 `advice`（怎么补）。
- `result.findings[]`：每条含 `level`（P0/P1/P2）、`category`、`line`（**原文行号**）、`message`（含算式与差额）、
  `advice`、`basis`（引用原文整行）。
- `result.summary`：`rows / parts / periods / materials / total / p0 / p1 / p2 /
  planned_total / issued_total / actual_total / loss_total / verdict`
  （`NO_ISSUE_FOUND` | `NEEDS_REVIEW` | `ERROR_FOUND`）。
- `result.scope`：本次执行的 `checks`、未执行的 `checks_not_run`、`loss_rate_cap`（上限口径来源）、
  `tolerance`、`rate_tolerance`、`executed_locally: true`、`network_used: false`。
- `result.checks_out_of_scope`：本工具**根本不做**的判断清单（边界诚实）。
- CLI 退出码：`0` 已执行检查 / `1` 没给入参 / `3` 材料不足 / `4` 入参读不到或无法解析 / `9` 未预期错误。

## 常见错法（本产品专属）

1. **损耗率的分母写成需用计划量或实耗量**：本表口径是 损耗率 = 损耗量 ÷ **领用量**。
   分母换成计划量时，只要领用量与计划量不等，每一行的损耗率都会不对（而且方向一致地偏大或偏小）。
2. **损耗量倒挤**：先按经验写一个损耗率，再反推 损耗量 = 领用量 × 损耗率，结果与「领用量 − 实耗量」差几毛几分 ——
   两条算式必须同时成立，报出来先看是哪一列被动过。
3. **上限列填成小数比率**：这一列按**百分数**填（3.00 表示 3.00%）；绝对值小于 1 的数按比率口径换算
   （0.03 ⇒ 3.00），但写成「0.03%」就会被当成 0.03%，绝大多数行都会判超限。
4. **以领代耗**：现场还有一堆料没耗用就不办退库，损耗量直接把余料算进损耗 ——
   会同时带出损耗率超上限与实耗超计划，先办退库单再跑这张表。
5. **同一分部分项同一材料拆成多行领料**却都写同一个材料名称与规格：会被判重复材料行，用量与损耗被重复汇总；
   分批领料请合并成一行，或在规格 / 备注里区分批次。
6. **合计行用上月表或计划表的数**：合计行必须等于各明细行相加；差额通常是漏了一行明细、某行被重复计入，
   或者合计是从别的表抄过来的。
7. **用「—」「待填」「无」「N/A」代替 0.00**：占位符一律按"没填"处理，那一行的损耗勾稽核不动 ——
   该是 0 就写 0.00。

## 边界（请务必知道）

- **不判断需用量定额是否合理**（定额、损耗率上限以施工定额、投标文件与合同约定为准）；
