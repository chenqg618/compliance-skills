# 承运司机运费结算核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：物流公司、货主车队、专线公司的**财务 / 调度 / 对账岗**在**每月给承运商与个体司机结算运费时**，
必须把这张结算单核一遍才能放款。回单缺失被扣、油卡抵扣重复、单价按错档，正是司机与公司每月都要吵的几件事。

**这张表会逐项核对什么**：
· 运费 = 结算数量 × 结算单价
· 应付运费 = 运费 − 回单扣款 − 油卡抵扣 − 罚款抵扣 − 押金扣留 + 代垫过路费
· 对账单（合计行）应付运费 = 各明细行应付运费之和，不符时报出差异金额并定位差异单
· 合计行逐列复核（结算数量 / 运费 / 各项抵扣 / 代垫过路费，单价是比率不参与加总）
· 同一司机同一期间同一运单号重复行、空白与占位符、金额为负

每条结论都带**原文行号与司机 / 运单号**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

1. 运费复算（结算数量 × 结算单价 = 运费）
2. 逐单应付运费复算（运费 − 回单扣款 − 油卡抵扣 − 罚款抵扣 − 押金扣留 + 代垫过路费 = 应付运费）
3. 对账单合计勾稽（合计行应付运费 = 各明细行应付运费之和，不符时报出差异金额并定位差异单）
4. 合计行逐列复核（结算数量 / 运费 / 各项抵扣 / 代垫过路费）
5. 同一司机同一期间同一运单号重复行检测
6. 空白与占位符检测
7. 金额为负检测

（检查项由引擎的 `CHECKS_GIVEN` 导出，跑 `--sample` 会打印实际执行了哪些；
本版本不包含的 5 项列在 `CHECKS_WITHHELD` 里，不做也不假装做。）

```bash

```

表头缺列会明确告诉你缺哪列（缺一列抵扣就报缺列，不会按 0 替你假设"没有这项抵扣"）。

## 常见错法（这张表里真的会有人这么填）

1. **单价按错档（按里程 vs 按吨公里）**：同一结算期、同一司机、同一结算方式只应有一档单价。
   把吨公里单价填进按里程的单子（或调价后新旧价混着算），一整列运费会差几倍；
   而且这张表**内部还自洽**（运费 = 数量 × 那个错单价），只看算术看不出来，必须拿运价合同核。
2. **回单没回来就按全额放款**：回单状态其实是「未回 / 未签收」，回单扣款栏却留空、
   也没写"未回"。签收单不回来就放款，一旦货损、货差或客户拒收，这笔运费追不回来。
3. **油卡抵扣重复计扣**：同一张油卡充值单号在两张单上各抵了一次，
   或者抵扣栏填了金额、油卡充值单号与扣款依据却都空着 —— 司机看到的只有"被扣了钱"。
4. **押金 / 质保金留空与填 0 混用**：这一列填 `0.00` 表示"本月确实没有扣留"，
   留空表示"不知道扣没扣"。留空时本工具**不会**替你按 0 算，会直接报这一格缺失；
   押金在一个月扣了一次、下个月忘了停又扣一次，是最常见的重复扣款。
5. **代垫过路费漏加、或对账单合计改过没刷新**：代垫过路费是**加项**（应付 = 运费 − 抵扣 + 代垫），
   漏加一张单的过路费，司机就少拿一笔；另一个高频错法是明细单改对了、合计行忘了重算，
   结果对账单金额与明细对不上。
