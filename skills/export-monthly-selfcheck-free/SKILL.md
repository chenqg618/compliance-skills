# 外贸月度自查包（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：分段外贸核对材料的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这 3 类核对里真的会犯的错）

1. **退税率套错商品编码**：一张报关单下混装好几个商品编码，退税率各不相同（13% / 9% / 0%），
   申报时却按「大类」统一填了一个税率。本包会核「不得免征和抵扣税额 = 离岸价 × 汇率 ×（征税率 − 退税率）」
   与「免抵退税额 = 离岸价 × 汇率 × 退税率」这两条复算式 —— **式子照样平，退税额却是错的**：
   哪个商品编码该配哪个退税率，表里认不出来，得你自己对《出口退税率文库》。
2. **不得免征和抵扣税额漏算或反推**：征税率 13%、退税率 10% 时，那 3% 的征退税差必须转出。
   常见错法是把这一列直接填 0（当成出口免税），或拿「应退税额 ÷ 退税率」反推一个数填进去。
   只要填的数与「离岸价 × 汇率 ×（征税率 − 退税率）」对不上，逐行复算立刻报出来，合计行也跟着不平。
3. **报关金额与发票金额口径不一致**：报关单按 CIF 报、出口发票按 FOB 开（或反过来），
   运保费、佣金、折扣只混在其中一个数里；也常见「报关金额含佣金、发票金额已扣佣金」却没人拉平。
   本包只能把「差额」算给你看，**两边该不该是同一个口径要你自己定** —— 口径没拉平，
   差额会永久挂着，后面的退税基数与收汇核销一起错。
4. **收汇与报关跨期，用假数据把差额抹平**：报关在 1 月、收汇在 3 月，或本期收的是上一票的尾款。
   为了「表好看」直接把「已收汇」填成「应收外汇」、让核销差额恒为 0 —— 这是最危险的一种干净：
   跨期差额根本没挂账，等外管核销或税务比对才发现。如实在差额列反映，才查得出来。
5. **汇兑损益用错汇率（月初 / 月末 / 交易日混用）**：外币结算段核的是
   「记账本位币 = 外币金额 × 记账汇率」与「汇兑损益 = 结算本位币 − 记账本位币」。
   本月用月初汇率、下月改月末汇率，或把结算汇率误填进记账汇率列（两列一相等，损益就被抹成 0），
   复算式一跑就报。**该取哪一天的汇率是会计政策问题，工具只核你有没有按自己填的汇率算对。**
