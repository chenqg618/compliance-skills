# 学费与退费核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：教培机构**每天都在处理退费**，而金额最容易吵起来 ——
已耗课费 = 已上课时 × 课时单价；应退学费 = 已缴 − 已耗；差额 = 应退 − 实退（**正数=还欠学员**）。
争议几乎都在「课时单价按折扣价还是原价」与「课时算到哪一天」。

**这张表会逐项核对什么**：
· 已耗课费 = 已上课时 × 课时单价；应退学费 = 已缴学费 − 已耗课费
· 差额 = 应退学费 − 实退学费；合计行逐列复核（课时单价列不参与求和）；重复与空缺检测

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. 请补上这些再跑；材料不足时本工具不做任何认定，也不套用默认值。
2. **课时单价口径是退费争议的第一现场**：按折扣后的实收单价，还是按课程原价？
3. 应退 = 已缴 − 已耗；若还要扣违约金/手续费，应在本表显式列示，不要悄悄并进已耗课费。
4. 差额 = 应退 − 实退；**正数表示还欠学员**，这类余额不清会直接变成投诉。
5. 注意：**课时单价是单价，不能按行相加**（合计行里应为空）。


## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 已上课时超过总课时检测（超上，需按合同另议）
- 已耗课费超过已缴学费检测
- 应退学费为负检测
- 差额绝对值超过给定阈值检测（阈值由入参 tolerance 给出；未给出则本项不执行）
- 课时单价或总课时非正检测

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。
