# 银行流水对账核对（免费）

> 一句话：把**银行流水**和**企业账面记录**贴成两段，逐笔配对、列出两侧**未达账项** —— 不需要付款，也不需要注册。

**完全免费**：不需要付款、不需要注册、不需要配置任何 API Key，直接调用即可。


## 什么时候用

- 每月末对账：银行流水和企业账对不上，想知道**到底是哪几笔**
- 想知道**银行有、账上没有**的有哪些（漏记、手续费、利息、跨月入账）
- 想知道**账上有、银行没有**的有哪些（已开出未收、在途未达、跨期）
- 怀疑某一笔**被重复录入了两次**

## 这个免费版查什么

| # | 检查项 |
|---|---|
| 1 | 逐笔自动配对：金额相等 且 日期相差不超过 3 天 |
| 2 | 未达账项清单：银行有账上无 / 账上有银行无（含笔数与合计） |
| 3 | 单侧重复记录检测（同日期同金额出现两次以上） |
| 4 | 两侧笔数与金额合计的对比表 |

**金额会做归一化**：`1,240.00`、`1240`、`-¥1,240.00`、`(1,240.00)` 都被认成同一个数，
不会因为写法不同就报错。**摘要文字不参与配对** —— 只认金额和日期，避免被"写法不同"干扰。

## 怎么用

```bash
node scripts/run.mjs --sample
node scripts/run.mjs --input my-recon.json
node scripts/run.mjs --input my-recon.json --json
```

入参两种写法，任选：

```json
{ "bank": [
    { "date": "2026-05-08", "amount": -1240.00, "memo": "酒店消费" },
    { "date": "2026-05-07", "amount": -86.00,   "memo": "出租车" }
  ],
  "book": [
    { "date": "2026-05-08", "amount": -1240.00, "memo": "差旅住宿" },
    { "date": "2026-05-07", "amount": -86.00,   "memo": "打车费" }
  ] }
```

或者**直接给纯文本**：先写一行「银行」、再写一行「账面」，各自下面按行写「日期 金额 摘要」：

```
银行
2026-05-08 -1240.00 酒店消费
2026-05-07 -86.00 出租车

账面
2026-05-08 -1240.00 差旅住宿
2026-05-07 -86.00 打车费
```

日期支持 `2026-05-08`、`2026/5/8`、`2026年5月8日`。

### 退出码

| 码 | 含义 |
|---|---|
| 0 | 已执行检查 |
| 1 | 没给入参 |
| 3 | **材料不足 —— 此时不给结论**（既不说"账平"，也不说"账不平"） |
| 4 | 入参文件读不到或无法解析 |
| 9 | 未预期错误 |

## 这个免费版不包含

以下检查项**不在本版本范围内**，调用时也不会执行：

- 可疑配对（金额相近但不相等，差在容差内 —— 常在手续费、汇差、笔误）
- 疑似跨期未达（另一侧有同金额记录，但日期超出匹配窗口）
- 对账恒等式校验（银行合计 − 账面合计 = 银行未达 − 账面未达）
- 自定义匹配窗口与金额容差（dayWindow / toleranceAbs）

- 本工具只做**逐笔配对与找差异**，**不判断哪些差异该做未达账项调整** —— 那是会计的事；
