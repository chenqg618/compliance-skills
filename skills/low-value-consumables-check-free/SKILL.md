# 低值易耗品与周转材料摊销核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**制造/餐饮/零售类公司的成本会计与仓管**，在**月度存货与费用结转、以及年度盘点之前**。低值易耗品与周转材料（工具、模具、包装物、劳保用品）金额小、流动性大，最容易"账实不符"：

- 期末数量 = 期初数量 + 本期入库数量 − 本期领用数量；
- 期末金额 = 期初金额 + 本期入库金额 − 本期摊销金额；
- 本期摊销 ≤ 期初金额 + 本期入库金额（不能超摊）。

## 这个免费版查什么

1. **合计行逐列复核**（数量与金额共 9 列）；
2. **期末数量滚存关系**（P0）；
3. **期末金额滚存关系**（P0）；
4. **本期摊销不超过可摊总额**（P0）；
5. **累计已摊销不超过可摊总额**（P1）；
6. **类别+名称重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论并报「列缺失」）。

## 常见错法（这些表里真的会有人这么填）

1. **领用数量含"部门领用未出库"**：领用要以**出库单**为准，含未出库的领用会让期末数量偏小、账实不符。
2. **五五摊销法只摊一次**：五五摊销是**领用时摊一半、报废时再摊一半**，只摊一次会让累计摊销长期偏低。
3. **期末金额直接按"数量 × 单价"填而不与滚存关系对齐**：本工具核的是**金额滚存**（期初 + 入库 − 摊销 = 期末），单价法只作你的内部口径。
4. **不同摊销方法混在一张表里却不写方法**：完整档会提示按一次转销/五五/分次写清，否则跨期无法复核。
5. **同一物品按仓库拆多行、类别名不一致**：会报重复行；请把"类别+名称"写成同一口径或用仓库维度单独建表。

## 边界（请务必知道）

- **不做**会计判断：某件物品算不算低值易耗品/周转材料、用哪种摊销方法，请按公司会计政策判断；
- **不代替**盘点程序或出具鉴证意见，也不判断盘盈盘亏的账务处理；
- **不核对**入库单、出库单、发票的**真伪**，也不与仓储/WMS 系统逐行比对；
- **不读取** WMS / ERP / 财务系统的导出文件——需要你先导出成文本贴进来；
- **不判断**相关支出的税前扣除时点（属于税务判断）。
