## 常见错法（这张表里真的会有人这么填）

1. **把「全部销售额」填成「对应销售额」**：分母是当期**全部**销售额（应税 + 免税 + 简易计税一起），填成对应销售额会把转出比例顶到 100%，转出额被放大成整笔进项税额。
2. **「转出合计」填成全表总计**：这一列是**按期间**的 —— 同一期间有几个转出项目就要相加；填成整张表的总计会被判成与各项目之和不符。
3. **同一期间同一项目开两行**：比如按货物/服务拆成两行却都叫「免税项目」，转出额会被重复计算；项目名要能区分（免税-货物 / 免税-服务）。
4. **比例写法不统一**：`5%`、`0.05`、`5` 都会被认成 5%；但想写 `0.5%` 却写成 `0.5` 就会被当成 50% —— 整列统一带 `%` 最稳。
5. **免税/集体福利/非正常损失填了销售额却没算转出**：这些对应的进项税额必须转出，漏转就是少缴税（补税并按日加收滞纳金）；表里留 0 或空白都要能说清理由。
