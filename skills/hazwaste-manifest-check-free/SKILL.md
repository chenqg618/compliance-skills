# 危险废物转移联单与台账核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**危险废物（HW 类）产生单位每月（每季）结账前，以及每年在固体废物管理信息系统做上年度申报之前**，
财务、安环、危废管理员必须把三套材料对一遍：危险废物**管理台账**、危险废物**转移联单**（电子/纸质）、
以及**贮存与出入库记录、处置合同结算**。按《固体废物污染环境防治法》，管理台账、转移联单、
危险废物管理计划都是法定义务，年度申报要填上一年度的产生量、贮存量、转移量与利用处置量 ——
数量或金额对不上就要查，错报、漏报会被处罚，报错了还要更正申报。

具体该在哪些时刻跑这个工具：

- 每月（每季）结账前：台账上每一类废物的「期初贮存 + 本期产生 − 本期转移 = 期末贮存」要能算平；
- 拿到联单回单后：同一张联单，台账上的转移量要与联单上的转移量一致，
  联单金额要与「处置单价 × 数量 + 运费 + 包装费」一致；
- 做完一批转移后：**联单号是唯一凭证**，同一联单号在台账里出现两次，往往意味着同一次转移被记了两遍
  （转移量和金额都翻倍，年度申报的量也会跟着虚高）；
- 从 Excel 导出台账后：导出的表常带一行「合计」，它的**每一列**（包括期初/期末贮存，不只是金额）
  都要等于明细之和；
- 年度申报填报前：先把上面这些核干净 —— 申报数据就是从台账和联单来的。

这些格子**都能手算复现**，所以本工具把它做成**确定性核对**：每条结论都带原文行号与具体数字，
可被第三方用同一口径复算；材料不足时**不给结论**。

## 这个免费版查什么（只执行下面 6 项）

1. **产生量与贮存量勾稽**：逐行复算 期初贮存 + 本期产生 − 本期转移 = 期末贮存，差额不为零即列出差额。
2. **转移联单与台账的数量一致性**：同一联单号，台账本期转移合计 = 联单转移量合计。
3. **转移联单金额勾稽**：联单转移量 × 处置单价 + 运费 + 包装费 = 联单金额（含运费/包装费时按列勾稽）。
4. **同一联单号重复登记**：联单号在本表内必须唯一，出现两次以上即列出（可能重复计转移量）。
5. **合计行逐列复核**：合计行每一列 = 明细之和，**贮存列也要对**，不是只核金额。
6. **必需字段缺失与数值格式检测**：废物类别、废物代码、单位、期初贮存、本期产生、本期转移、期末贮存、
   联单号、转移量、处置单价、联单金额，空白/占位符/认不出的数值逐处点名。

## 这个免费版不包含（5 项，如实列出，本版本不执行）

1. 管理计划与执行量对比（计划转移量 vs 实际转移量，超计划提示）；
2. 危险废物贮存超期检测（期末仍有贮存、且按入库日期算已超过一年）；
3. 跨期归属检测（联单日期不在本期统计期间内）；
4. 接收单位合同单价一致性（同一接收单位在不同联单上单价不一致）；
5. 分废物类别 × 接收单位的汇总清单（按差额排序、给出可整改动作）。

上面 5 项在本版本里**一项都不会执行**，也不会被伪造出来；跑 `--sample` 会打印实际执行了哪些。
