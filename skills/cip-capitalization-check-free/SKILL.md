# 在建工程转固与利息资本化核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`scripts/engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：有工程或产线建设的企业，**每月做账、每年审计时必须核**这张在建工程台账。
转固时点错、利息该资本化却费用化（或反之）是审计调整的高发区，而这张表纯粹是算术与口径 ——
项目一多、月份一长，人眼极易错。

**这张表会逐项核对什么（免费版实际执行的全部检查项）**：

· **工程成本归集复算**：材料费 + 人工费 + 分包费 + 其他费用 = 本期发生成本
· **本期发生额计入累计一致**：上期期末累计 + 本期发生额 = 本期累计已发生成本
· **账面余额勾稽**：在建工程账面余额 = 上期期末余额 + 本期各成本类别成本之和
· **利息资本化复算**：资本化期间占用资金 × 资本化率 × 本期资本化月数 ÷ 12 = 本期资本化利息
· **合计行逐列复核**（累计已发生成本按各项目期末余额 / 本期资本化利息）
· **转固金额与明细勾稽**：台账合计要等于各项目期末在建工程余额之和（也就是转固时应当结转的数）
· **成本类别口径白名单**（材料费 / 人工费 / 分包费 / 其他费用）
· **重复行检测**（同一项目 + 同一期间 + 同一成本类别）
· **空缺与占位符检测**

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 入参怎么写（一张表就够）

把在建工程台账（**含表头**）从 Excel 直接复制成文本贴进来，Tab 分隔最稳。需要的列：

```text
项目名称 期间 成本类别 本期发生成本 累计已发生成本 在建工程账面余额
达到可使用状态日期 转固日期 是否停工 停工起止 资本化期间占用资金
本期资本化月数 资本化率 本期资本化利息 转固金额暂估 借款合同资本化率
```

台账写法（本工具按这个口径复算）：**一个项目一个期间写多行成本类别**；

· 「本期发生成本」只在每个"项目 × 期间"的**第一行**写一次（= 该期各项成本之和），其余类别行留空；
· 「累计已发生成本」= 上期期末累计 + 本期发生额，同一个"项目 × 期间"的各行写**同一个数**；
· 「在建工程账面余额」只在每个"项目 × 期间"的第一行写一次（= 该期期末的项目余额）；
· 利息（占用资金 / 资本化月数 / 资本化率 / 本期资本化利息）只写在**占用专门借款资金**的那一行。

首期没有上期可比，所以首期的累计与余额不做勾稽（本工具**不给**首期的这类结论，也不套默认值）。

## 常见错法（这张台账里真的会有人这么填）

1. **把"本期发生成本"分摊到每个成本类别行**：本工具按"项目 × 期间首行写一次"的口径复算，
   分行重复写会让归集复算与累计勾稽一起报错 —— 请只在首行写一次，其余类别行留空。
2. **同一个"项目 × 期间"的累计列填成每行不同的数**：本期只发生材料费，人工费行却填了别的累计数 ——
   同一期间各行的累计必须相同（= 上期期末累计 + 本期发生额）。
3. **只在本期首行写余额、却把"本期发生额"拆到多行**：余额只在首行写一次是对的，但它必须等于
   **本期各成本类别成本之和**；把金额摊到多行会让余额勾稽报出差额。
4. **利息资本化只填金额、不填占用资金与月数**：这样复算不出来 —— 本工具**不会**替你反推，
   该行跳过复算并如实说明缺哪几格，不会用默认值编一个数。
5. **成本类别自由发挥**（"设备款""钢材""预付工程款""待摊"）：不在四类白名单内会命中口径提示；
   请归并到 材料费/人工费/分包费/其他费用，确需细分就保留四类前缀（如"材料费-钢材"）。
6. **同一项目同期同类别复制两行**：会被判成重复行 —— 两笔业务请用不同成本类别，或分行写清摘要。
7. **停工/中断期间照样把利息挂进在建工程**：免费版只复算算术，停工期间照样能算平；
   这类口径问题由完整档核（见下）。
