# 制造费用分摊与吸收核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**、材料不出本机。

## 什么时候用

**谁在什么时候用**：成本会计 / 车间核算员 / 财务主管在**每月结账、成本核算、月度经营分析**这类固定节点上，
必须先把「制造费用归集与分摊表」核一遍，才能结转产品成本、才能拿它算存货与毛利。
这张表错的方向只有两个 —— **费用摊少了**（有车间或费用项目漏摊，未分摊虚高）或
**摊重了 / 摊多了**（同一行被算两次，分摊合计超过本期归集的费用），
两个方向都会在成本结转和审计抽样上暴露，而且**结完账就看不出来了**。

**这张表会逐项核对什么**（免费版执行 6 类，逐条都带**原文行号**）：

1. **分摊率复算** —— 分摊金额 ÷ 分摊基数 = 分摊率，差 0.01 也会报。
2. **分摊金额逐行复算** —— 分摊基数 × 分摊率 = 分摊金额，逐行复算，不看合计。
3. **分摊合计勾稽** —— 费用总额 − 未分摊金额 = 分摊合计（已分摊 + 未分摊必须正好等于本期归集的制造费用）。
4. **吸收率与吸收差异** —— 分摊合计 ÷ 费用总额 = 吸收率；同时给出吸收差异（费用总额 − 分摊合计）的金额。
5. **重复行检测** —— 同一期间 + 同一车间 + 同一费用项目出现两次以上。
6. **空缺与占位符检测** —— 必需列为空或写着「待填 / 待补 / —」这类占位符。

每条结论都带**原文行号与算式**，可被第三方用同一份输入复算；
材料不足时**不给结论**，会明确列出还缺什么，也不会用默认值编出结论。

## 这个免费版查什么

上面 6 类就是本版本执行的全部检查项。跑 `--sample` 会在 `scope.checks` 里打印本次实际执行了哪些，
`scope.checks_not_run` 会如实列出**本版本没有执行**的检查项（只列出，不会伪造结论）。

## 出参

- `status`：`success` 才有结论；`insufficient_input` 表示材料不足，此时**没有** `result`、**没有** `findings`，
  只有 `missing`（缺什么）与 `advice`（怎么补）。
- `result.findings[]`：每条含 `level`（P0/P1）、`category`、`line`（**原文行号**）、`message`（含算式与差额）。
- `result.summary`：`rows / periods / workshops / total / p0 / p1 / p2 / verdict`
  （`NO_ISSUE_FOUND` | `NEEDS_REVIEW` | `ERROR_FOUND`）。
- `result.scope`：本次执行的 `checks`、未执行的 `checks_not_run`、`base_total`、`allocated_total`、
  `tolerance`、`executed_locally: true`、`network_used: false`。
- `result.checks_out_of_scope`：本工具**根本不做**的判断清单（边界诚实）。
- CLI 退出码：`0` 已执行检查 / `1` 没给入参 / `3` 材料不足 / `4` 入参读不到或无法解析 / `9` 未预期错误。

## 常见错法（本产品专属）

1. **分摊率列填的是"分摊金额 ÷ 车间费用合计"**：分摊率的分子是**这一行的分摊金额**，不是整个车间的费用合计；
   用车间合计去算，每一行都会得到同一个费率，而金额又是按行给的 ⇒ 费率与金额当场对不上。
2. **期间级口径列只在其中一行改数**：费用总额 / 未分摊金额 / 分摊合计 / 吸收率是**整期**口径，
   同一期间里每一行必须填同一个数；只改了某一行，勾稽与吸收率会立刻报出来。
3. **未分摊金额与分摊合计两列填反**：把"还没分摊的"填进分摊合计、把"已分摊的"填进未分摊，
   「费用总额 − 未分摊金额 = 分摊合计」必然不成立 —— 报出来先看这两列是不是互换了。
4. **吸收率填成小数比率**：这一列按百分数填（95.83）。填 0.9583 也能认（不超过 1.5 视为比率、自动换算成 95.83）；
   但填 0.96 会被当成 96%，与算出来的 95.83% 差 0.17 个百分点，会被报出来。
5. **同一期间同一车间的同一个费用项目拆成多行**：水电费拆成"动力 + 照明"两行却都写「水电费」，
   会被判重复行（分摊基数与分摊金额被重复计入）；要么合并成一行，要么把费用项目写细（动力费 / 照明费）。
6. **拿「未分摊金额」当兜底平衡项**：为了凑平把差额塞进未分摊，账面上勾稽是通过了，
   但"到底哪个车间哪一项没摊出去"就永远查不出来 —— 未分摊应当是确实没摊出去的那部分。

- **不规定分摊率该定多少**（工时 / 机时口径、费用归集范围、车间划分，以本单位成本核算办法为准）；
