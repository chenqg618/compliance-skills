# 增值税加计抵减核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：适用**增值税加计抵减**政策的一般纳税人（生产、生活性服务业等），
在**每月申报增值税、填写加计抵减台账之前**，必须把台账逐期滚动核一遍：

- 本期计提加计抵减额 = 当期可抵扣进项税额 × 加计抵减比例；
- 期末加计抵减余额 = 期初余额 + 本期计提 − 本期调减 − 本期实际抵减；
- 本期实际抵减 ≤ 抵减前应纳税额（抵减不能超过当期应纳税额）；期末余额 ≥ 0。

台账这几列一旦滚不上，申报表附表也会跟着错；而这类错误**全都能算出来对错**。

## 这个免费版查什么

1. **合计行逐列复核**：销售额 / 四项服务销售额 / 进项税额 / 计提 / 调减 / 实际抵减（**余额列不相加**）；
2. **期末余额 = 期初 + 本期计提 − 本期调减 − 本期实际抵减**（滚动关系，最常错的一条）；
3. **本期实际抵减 ≤ 抵减前应纳税额**；
4. **期末余额为负**检测；
5. **同一所属期重复行**检测；
6. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这张台账里真的会有人这么填）

1. **把"期初余额"当成上月计提额**：期初余额是**上期期末结转**的可用额度，不是上月计提数；填错会让整条滚动关系断掉。
2. **本期调减额留空却实际发生了调减**（进项转出、红冲时要做调减）：留空等于默认 0，会算出偏大的期末余额。
3. **实际抵减填成"计提额"**：实际抵减受**当期应纳税额**限制，两者通常不等；相等往往说明没做限额判断。
4. **比例写成整数 10（而不是 10%）**：本工具两种写法都认（10 = 10%），但**12%**这种非政策档位会被点出来核对政策依据。
5. **同一所属期分两次粘贴**（补录时重复）：会报重复行；如确实分两笔，请合并成一行或注明凭证号。
