# 广告文案合规预检（免费）

> 一句话：发布前扫一遍文案里的绝对化用语，并且按监管的执法指南判断**该不该报**，不需要付款，也不需要注册。

**完全免费**：不需要付款、不需要注册、不需要配置任何 API Key，直接调用即可。


## 什么时候用

- 准备发一条商品文案、详情页或口播稿，想先确认有没有绝对化用语
- 已经在用别的极限词工具，但被「最后」「最近」「一站式」这类误报烦到了
- 想知道某个词到底算不算违法、依据是哪一条

## 这个免费版查什么

| # | 检查项 |
|---|---|
| 1 | 绝对化用语检测 |
| 2 | 《广告绝对化用语执法指南》豁免判定 |

- 绝对化用语检测：只报**真正带"最优/第一/唯一"声称**的写法，不报单字「最」「一」
- **豁免判定**：命中后先按《执法指南》第五条、第六条判断该不该报 —— 「最后」「最近」「一站式」「第一时间」「最佳食用期限」这类正常用语**不会被误报**，而是单独列进 `exempted` 并写明豁免依据，让你看得见我们"故意没报"的东西
- 每条结论都带法条依据，可被第三方用同一份规则复算

## 这个免费版不包含

以下检查项**不在本版本范围内**，调用时也不会执行：

- 医疗／药品／医美违禁表述
- 保健食品功效断言
- 教育培训保证性承诺
- 投资理财与招商承诺
- 房地产升值回报承诺
- 虚假广告类保证性承诺
- 批量文案检测

## 怎么调用

### 方式一：命令行脚本（最省事）

```bash
node scripts/run.mjs --sample
node scripts/run.mjs --input my-input.json
node scripts/run.mjs --input my-input.json --json
```

### 方式二：直接引用引擎（接进自己的流程）

脚本本身不做计算，真正的检查在同目录的 `scripts/engine/ad-compliance.js`（纯 Node 标准库，CommonJS），可以直接引用：

```js
const engine = require('./scripts/engine/ad-compliance.js');
const outcome = engine.run(payload);
// outcome.status === 'success'            → outcome.result 就是结果
// outcome.status === 'insufficient_input' → outcome.missing 列出缺什么（此时不出结论）
```

所有检查都在**本机**完成：不联网、不外发材料、不需要任何凭证。

## 入参

把待检文案粘进 text 即可；也可以给 texts 数组一次传多条。

```json
{
  "text": "本品牌全国销量第一，效果最好，100%有效。最后一步点击提交即可，我们提供一站式服务。"
}
```

## 返回

返回 `ok: true` 与 `result`：`checks_given` **原样列出本次实际执行了哪些检查项**，
`checks_withheld` 列出本版本不包含的检查项。**不会用默认值编造结论。**

材料不足时（入参为空、只有空白、只有一个字符、解析不出任何明细行）**不出结论**：
会说明缺什么，并以退出码 `3` 结束；正常执行退出码为 `0`。

## 使用限制

- 在本机执行：不联网、不外发材料、没有调用次数上限，也不需要任何凭证。
- 输出的是**AI核对结果**，不是认定、不是评分。

## 反模式

- ❌ 把它的输出当作评标结论 —— 它只做AI核对，认定权在评标委员会。
- ❌ 拿它替代对招标文件的实质响应检查 —— 本版本不含该类检查。
- ❌ 输入残缺时怪结果不对 —— 检查项依赖你提供的字段，缺字段的检查项不会被伪造出来。
