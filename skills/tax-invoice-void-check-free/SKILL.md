# 发票作废与红冲核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：发票作废与红冲台账的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（6 项）

| # | 检查项 | 判据（可手算复现） |
|---|---|---|
| 1 | 净开票金额勾稽 | 净开票金额 = 开票金额 − 作废金额 − 红冲金额 |
| 2 | 红冲金额勾稽 | 红冲金额 = 原发票金额 − 折让金额（有红冲的行） |
| 3 | 合计行逐列复核 | 合计行每一列 = 明细行该列之和 |
| 4 | 同一发票号码重复行 | 同一票号出现两行 ⇒ 作废份数/红冲金额会被重复计算 |
| 5 | 空白与占位符 | 期间、发票号码、原发票金额、开票金额、作废金额、红冲金额、净开票金额缺一不可 |
| 6 | 金额为负 | 本表按正数登记发生额；红冲填「红冲金额」列，不用负号 |

**本版本不包含**（由完整版追加）：红冲金额超过原发票金额检测、作废发票已跨月提示、
作废率超过参考上限提示、作废或红冲无原因说明提示、净开票金额与申报表口径不一致提示。

## 常见错法（这张表里真的会有人这么填）

1. **跨月的那张票也填成"作废"**：月份已过只能开红字发票冲减，写成作废会让「作废份数」与「红冲金额」两边都对不上申报口径。
2. **红冲金额用负号填在原金额列里**：本表按正数登记发生额，红冲请填在「红冲金额」列；用负号会让"金额为负"整列报警，净额方向也会反过来。
3. **折让金额只在备注里写一句**：红冲金额 = 原发票金额 − 折让金额，折让金额不填这一列，部分退货的红冲就核不出对不对。
4. **同一张发票拆两行（一行作废、一行重开）却不换发票号码**：会报"同一发票号码出现多行"，作废份数被重复计算，重开的那张也认不出来。
5. **合计行是手填的，改了明细忘了改合计**：合计行必须逐列等于明细之和；漏改一处，整张表的勾稽结论就全错。
