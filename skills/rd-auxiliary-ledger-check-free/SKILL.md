# 研发费用辅助账与高新指标核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**高新技术企业（含拟认定/复审）的财务与研发管理岗**，在**月度归集研发费用、
以及高新年报与认定申报之前**：

- 本年归集金额 = 人员人工 + 直接投入 + 折旧摊销 + 设计试验费 + 其他费用；
- **其他费用占比一般不超过 20%**（高新口径，按项目汇总计算）；
- 高新口径要求**有人工投入**（人员人工为 0 是硬伤）。

> 与已有产品的区别：`rd-expense-check` 核的是**企业所得税加计扣除**归集（其他相关费用按前五项 10% 限额、
> 全部项目统一计算）；本产品核的是**高新口径的辅助账台账**（20% 上限按项目汇总、要求有人工）。

## 这个免费版查什么

1. **合计行逐列复核**（本年归集金额 / 五项明细）；
2. **本年归集金额 = 五项明细之和**（容差 0.02，P0）；
3. **其他费用占比超过 20%**（按项目汇总口径，P0）；
4. **任一项明细为负**（P0）；
5. **备注为空或占位符**（P1）；
6. **研发项目+费用类别重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论并报「列缺失」）。

## 常见错法（这些表里真的会有人这么填）

1. **其他费用按"单行占比"算**：单行占比恒为 100%，必须按**项目汇总后**算（本工具按项目汇总，别自己逐行判断）。
2. **把高新口径当加计扣除口径**：加计扣除的"其他相关费用"是前五项 **10%** 限额、按全部项目统一算；高新是 **20%**、按项目算，混用会得出相反结论。
3. **只有折旧摊销、没有人工**：高新材料里没有人工投入是硬伤，完整档会点出来。
4. **同一项目按费用类别拆行却不写类别**：会报重复行；请把"项目 + 费用类别"写全。
5. **备注写"研发用"**：要写清用途与归集依据（工时/领料/折旧分摊表），否则审计与认定专家都会追问。

## 边界（请务必知道）

- **不做**判断：某项支出**是否属于**研发费用、能否计入高新口径，请按《高新技术企业认定管理工作指引》与公司制度认定；
- **不代替**专项审计、认定申报或出具鉴证意见；
- **不核对**工时记录、领料单、折旧分摊表的**真伪**，也不与研发管理系统逐行比对；
- **不读取**研发管理系统 / ERP 的导出文件——需要你先导出成文本贴进来；
- **不判断**加计扣除与高新优惠的税务处理（属于税务判断，见同系列 `rd-expense-check`）。
