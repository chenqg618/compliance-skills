# 物流仓储与操作费核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：电商/制造的财务、供应链对账岗，**每月收到第三方仓库（3PL）的
仓储与操作费结算表、付款之前**，必须把这张表核一遍才能往下走 —— 账单最容易多收。

**这张表会逐项核对什么**：物流仓储与操作费结算表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

| # | 检查项 |
|---|---|
| 1 | 仓储费复算：库存体积（或托盘数）× 单价 × 库存天数 = 仓储费 |
| 2 | 账单合计复算：仓储费 + 操作费 + 超期费 + 退仓费 = 账单金额 |
| 3 | 合计行逐列复核（合计行 = 各明细行逐列相加） |
| 4 | 同一仓库同一期重复行检测 |
| 5 | 空白与占位符检测（仓库/期间/库存天数/仓储费/账单金额） |
| 6 | 数量或金额为负检测 |

免费版**只执行上面 6 项**；引擎里 `CHECKS_WITHHELD` 如实列出未执行的那几项，
跑 `--sample` 会打印实际执行了哪些。

## 怎么用

```bash
node scripts/run.mjs --sample                 # 先看样例
node scripts/run.mjs --input 你的材料.json     # 跑自己的材料
```

入参写法：

```json
{"text": "仓库\t期间\t库存体积\t托盘数\t单价\t库存天数\t仓储费\t操作费\t超期费\t退仓费\t账单金额\n上海仓\t2026-01\t1200\t60\t1.20\t31\t44640.00\t6800.00\t0.00\t0.00\t51440.00"}
```

把结算表（**含表头**）从 Excel 复制成文本粘进来即可，Tab 分隔最稳。

## 常见错法

1. **把「库存体积」当「托盘数」用（或反过来）**：仓储费 = 数量 × 单价 × 库存天数，
   两种计价基础的单价差一个量级（元/m³·天 vs 元/托·天）。表里同时给两列时，
   本工具按"哪种基础能算平就用哪种"，**两列都算不平才报**；只填一列时那一列必须对。
2. **账单金额不是加出来的**：直接照抄四项、或漏加某一项。看着"自己跟自己一致"，
   其实账单金额与逐项加总根本不是一个数 —— 这是多收钱最藏得住的地方。
3. **改了明细忘了改合计行**（或反过来只改合计行）：合计行与明细之和对不上，
   付款前最后一道人工复核就是看这里。
4. **同一仓库同一期贴了两行**：从 Excel 复制整月数据时把同一张账单贴了两遍，
   费用凭空翻倍；或者上月行没删掉。免费版会把重复行指出来（第几行、第几行）。
5. **用 `-` / `N/A` / `待补` 占位后忘了替换**：占位符被当成"没填"，
   关键列一空这条明细就无法复算；红字冲回也不要直接把负号塞进正常行，
   应当单独列一行并注明原因。
