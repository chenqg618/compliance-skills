# 医院耗材加成与零差率核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：医院 / 诊所的**物价员、耗材会计、财务**在**每月结账与物价自查前**必须把
卫生耗材这张表核一遍才能往下走 —— 零差率耗材被加价、可收费耗材（含植入类）收费价低于成本、
进销存对不上被认定"账实不符"，是每月都存在的合规与亏损点。

**这张表会逐项核对什么**（口径固定、可复算）：

- 结存数量 = 期初数量 + 入库数量 − 出库数量
- 结存金额 = 结存数量 × 采购单价（按进价计价的库存金额口径）
- 加成率 =（收费价 − 采购单价）÷ 采购单价
- 合计行逐列复核；同一期间同一耗材重复行检测；空白与占位符检测；数量、单价或金额为负检测

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

| 检查项 | 结论类别 | 级别 |
| --- | --- | --- |
| 结存数量勾稽 | 结存数量与复算不符 | P0 |
| 结存金额勾稽 | 结存金额与复算不符 | P0 |
| 加成率勾稽 | 加成率与复算不符 | P1 |
| 合计行逐列复核 | 合计行与明细之和不符 | P0 |
| 同一期间同一耗材重复行检测 | 同一期间同一耗材重复行 | P1 |
| 空白与占位符检测 | 关键字段缺失或为占位符 | P0 |
| 数量、单价或金额为负检测 | 数量或金额为负 | P0 |

**本免费版不做的合规判定**（属于完整档，见下面「需要完整档时（可选）」）：
不判断零差率耗材是否被加价、不判断收费价是否低于成本、不做进销存金额三段勾稽，
也不输出按影响金额排序的调整清单 —— 这一档只做**表内逐行复算**。

## 常见错法（这张表里真的会有人这么填）

1. **采购单价与收费价不是一个税口径**：进价按不含税填、收费价按含税填（或反过来），
   加成率会凭空多出或少了 13% 那一块（报「加成率与复算不符」，零差率品还会被完整档判成加价）。
   两个价格列请**统一含税或统一不含税**，并在备注里写清用的是哪个口径。
2. **零差率品的配送费 / 跟台费摊进了收费价**：植入类耗材按实际采购价据实收费，配送费、跟台费另计；
   一旦摊进「收费价」，收费价就高于采购单价 —— 免费档会报「加成率与复算不符」，
   完整档会进一步判成"零差率耗材被加价"。费用请单列，不要并进收费价。
3. **结存金额按收费价（零售价）挂账**：本工具按**采购单价（进价）**核
   `结存金额 = 结存数量 × 采购单价`，账上若按收费价挂库存金额，这一格会一直报
   「结存金额与复算不符」。先把计价口径统一，再跑这张表。
4. **退货回库、报损、赠送没有进算式**：算式只有三个加项/减项 ——
   `结存数量 = 期初 + 入库 − 出库`。退货回库要回填「入库数量」（或单独列示），
   报损与赠送要走「出库数量」；只在备注里写一句"已报废"不会进算式，
   结果是「结存数量与复算不符」—— 而这一格正是"账实不符"的认定口径。
5. **调价当月前后混用同一列**：物价文件调价当月，调价前采购的库存是旧价、调价后入库是新价，
   却在同一行只写一个「采购单价」和一个「收费价」：加成率与结存金额会同时报错
   （报「加成率与复算不符」「结存金额与复算不符」）。调价当月请**按调价前后分行列示**。

## 边界（请务必知道）

- **以你提供的采购单价与收费标准为准**：本工具**不判断地方物价政策是否适用**，
  也不判断集采中选价 / 挂网价 / 中标价本身填得对不对（以医保局、卫健委的价格文件与招采结果为准）。
- **不给医疗建议、不做诊疗判断**：只核表内可算关系（进销存勾稽、加成率 / 零差率、收费价与成本的关系）。
- **账上勾稽通过不代表实物在场**：那要靠耗材库实物盘点。
- 材料不足时**不给结论**，也不会输出「未发现问题」。
