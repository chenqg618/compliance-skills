# 现金流预测与实际差异核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务 / 资金岗在**每月资金例会之前**、以及**滚动预测上会之前**，
必须把「预测 vs 实际」这张差异表逐项核一遍才能往下走 —— 例会上每一句「差异原因是……」
「下期滚动预测是……」都建立在这张表上。**预测不准会直接影响资金链安全**。

**这张表会逐项核对什么**：现金流预测与实际差异表的逐行算术与勾稽 ——
预测/实际的净流量、差异列、合计行、重复行、空缺与金额为负。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

1. 净流量复算：预测净流量 = 预测流入 − 预测流出；实际净流量 = 实际流入 − 实际流出
2. 差异复算：差异 = 实际 − 预测（流入差异、流出差异、净流量差异三列各自复核）
3. 合计行逐列复核（合计行 = 各明细行之和）
4. 同一项目同一期重复行检测
5. 空白与占位符检测
6. 金额为负检测（流入 / 流出都必须非负）

## 常见错法（这张表里真的会有人这么填）

1. **「差异」只填了净流量那一列**：流入差异、流出差异、净流量差异是**三列各自**的勾稽，
   只填净流量差异时，流入/流出的差异原因就无从核对。
2. **差异的符号方向搞反**：差异 = **实际 − 预测**。实际低于预测是**负差异**，
   填成正数会让后面的差异率与方向判断同时失真。
3. **把负差异当成"金额为负"改掉**：差异列**本来就允许为负**，这不是错；
   要改的是**流入/流出**列 —— 那两列出现负号通常是方向填反了（付出的钱记成流入）。
4. **净流出被当成异常**：预测与实际都可能是净流出（当期集中付款），这是正常业务；
   真正危险的是**方向反转**（预测净流入、实际净流出）。
5. **预测为 0 的格子留空不写 0**：留空会被当作"没填"，写 0 才能看出这一格到底是"预测为零"
   还是"忘了填"—— 资金例会上这两者的解释完全不同。
