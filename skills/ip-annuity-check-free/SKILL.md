# 知识产权年费与续展台账核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：有商标/专利/著作权的企业，**每年（年费按年、按月分批到期）必须把这张台账核一遍** ——
通常由法务/知识产权专员发起，财务在付款前复核。漏缴年费不是"晚交一笔钱"：
**专利权会终止、商标会被撤销**，恢复要交滞纳金，有的情形根本恢复不了，损失远超年费本身。

**这张表会逐项核对什么**：
· 下次缴费日 = 上次缴费日 + 缴费周期（年 / 月，月末自动收敛）
· 已缴合计 = 官费 + 代理费
· 到期天数 = 下次缴费日 − 基准日（**基准日 = 台账内最新日期**）
· 同一申请号是否出现多行；关键字段是否空缺或写着占位符
· 缴费周期是否为正数、单位写得出来；日期是否倒挂（下次缴费日不晚于上次缴费日、转让日早于上次缴费日）
· 官费 / 代理费 / 已缴合计是否三者齐全（缺一项就算不出费用口径）

**官费与代理费一律由你的台账提供**：本工具**不判断任何国家/地区的官费标准、减缴比例与滞纳金费率** ——
那些要查官方费率表；这里只核表内可算的关系与日期一致性。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这张表里真的会有人这么填（常见错法）

1. **把「上次缴费日」写成缴费通知单的日期，而不是实际缴款到账日** —— 下次缴费日会整体前移或后移，排期跟着错。
2. **缴费周期只填数字、表头也不写单位**：`12` 到底是 12 个月还是 12 年？单位认不出来时这次就不给结论（本工具不替你猜）。
3. **月末日期直接加月**：`2024-02-28` 加 12 个月本工具按 `2025-02-28` 收敛；手工算成 `2025-03-01` 就会报"下次缴费日与复算不符"。
4. **官费填 0 但代理费留空**：三者缺一，费用口径就不可复算 —— 留空会报"缴费金额缺失"，请明确写 0。
5. **同一申请号给不同年度各开一行**：整表基准日取的是台账内最新日期；重复行会被逐行核出来，先确认哪一行才是本次要核的年度。
6. **把「已放弃」的行还留在待缴清单里**：免费版会提示同一申请号多行与空缺，但"放弃/转让与缴费记录是否矛盾"属于完整档的检查项。

## 这个免费版查什么

引擎导出 `CHECKS_GIVEN`（8 项，本次真的执行）与 `CHECKS_WITHHELD`（5 项，本版本**没有执行**）：
· 已执行：下次缴费日复算、已缴合计复算、到期天数额、申请号重复、空缺与占位符、周期非正或认不出单位、日期倒挂、缴费金额缺失。
· 未执行（完整档才有）：逾期待缴清单（含逾期月数与滞纳金档位，档位由输入给出）、90/180 天内到期排期表、
  台账状态与缴费记录一致性（已放弃/已转让却仍挂着待缴）、同一申请号重复计费、代理费异常（超同表中位数倍数）。

跑一次 `node scripts/run.mjs --sample` 会打印本版本实际执行的检查项与未执行的检查项 —— **不会把没查的说成查过了**。

## 这个工具会拦下什么（引擎原话）

1. 请补上这些再跑；材料不足时本工具不做任何认定，也不套用默认值
2. 下次缴费日是排期与失权判定的基准，错一天就可能错过缴费窗口；请按缴费通知单核回原值
3. 已缴合计与官费+代理费对不上，通常是有笔款没入账或被重复计入；金额口径要与缴费凭证一致
4. 同一权利多行会让年费与代理费一起被重复统计；确认哪一行才是本年度该核的那条
5. 缺这一格这笔年费就排不出期；补齐前本工具不会用 0 或默认值替你填

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断：
不判断官费标准与滞纳金费率、不代替官方期限监控与缴费、不判断权利是否真的有效或可否恢复、不给法律意见；
不读 `.xlsx`（需要你先导出成文本贴进来）。
材料不足时**不给结论**，也不会输出「未发现问题」。
