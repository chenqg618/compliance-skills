# 应付暂估与发票未到核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、应付会计在**每月月末结账**前必须把暂估台账核一遍 ——
货到票未到先暂估入账，发票到了再冲回暂估、按票入账；暂估不准，成本与利润跟着失真。

**这张表会逐项核对什么**：应付暂估台账的逐行复算、合计勾稽、重复单号、空缺与负值、跨期标记，
每条结论都带**原文行号与出处**，可被第三方用同一份输入复算。
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么（9 项）

1. 暂估入账金额勾稽（暂估入账金额 = 数量 × 单价）
2. 冲回金额与暂估金额勾稽（本期冲回不得超过本期暂估）
3. 暂估与发票差异勾稽（差异 = 发票金额 − 暂估入账金额）
4. 暂估余额勾稽（本期暂估余额 = 上期暂估余额 + 本期暂估 − 本期冲回）
5. 合计行逐列复核（每一列的合计是否等于各行之和）
6. 重复暂估单号检测
7. 关键字段空缺与占位符检测（含"标了已到票却没有发票金额"）
8. 金额为负检测
9. 跨期标记缺失检测（已到票标记未填或认不出写法）

## 表要长什么样（14 列，Tab 分隔最稳）

暂估单号、合同号、暂估所属期、数量、单价、暂估入账金额、已到票、发票金额、到票月份、
本期冲回金额、上期暂估余额、本期暂估余额、应付明细暂估余额、暂估与发票差异。
最后可以带一行「合计」—— 本工具会**逐列**核对它与明细行之和。

## 常见错法（这张表里真的会有人这么填）

1. **只暂估不冲回、也不标注到票**：发票到了仍挂着，负债和成本一起重复；买断档会按发票金额与挂账月数列出「已到票未冲」。
2. **冲回按含税金额、暂估按不含税**：差异列永远对不平，差额恰好是税额；两列必须同口径（都不含税）。
3. **同一张暂估单在暂估月和冲回月各录一行、单号照抄**：会报「暂估单号重复出现」；请用「-冲」后缀区分，或让每行只登记一笔业务。
4. **上期暂估余额手工抄上期期末，抄错一位**：余额勾稽（上期＋本期暂估−本期冲回）会当场报不符，而且这条链断了会一直挂账。
5. **单价直接填发票单价或含运费到岸价**：暂估金额 = 数量 × 单价 对不上；暂估单价应当与采购单/合同价一致。
6. **未到票的行把发票金额填 0 而不是留空**：差异会被算成 −暂估金额，冒出一堆假差异。
7. **「已到票」列空着不填**：跨期判定做不了，会报「已到票标记缺失」—— 本工具不会替你猜是到票还是没到票。
8. **应付明细暂估余额直接照抄本表余额**：那是"自己跟自己对"，两边同源的错误永远对不出来；要填应付账款明细账上的数。
