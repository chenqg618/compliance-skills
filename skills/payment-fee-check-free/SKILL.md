# 收款手续费核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**只要收钱就有手续费**（微信/支付宝/银联/信用卡），财务每月对账时
要么逐笔核（几十上百行核不动），要么干脆不看（那就一直在漏）。
平台账单上的手续费与"金额 × 费率 + 固定费"经常对不上，几块钱的差额累积起来是真金白银。

**这张表会逐项核对什么**：
· 应收手续费 = 交易金额 × 费率 + 固定费
· 差异 = 账单手续费 − 应收手续费（**符号写反会把多收/少收完全颠倒**）
· 结算金额 = 交易金额 − 账单手续费；合计行逐列复核；重复渠道与空缺检测

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. 请补上这些再跑；材料不足时本工具不做任何认定，也不套用默认值。
2. 费率或固定费录错是最常见原因；也可能是把渠道费率记成了"年化"或其他口径。
3. 差异 = 账单 − 应收；符号写反会让"多收"和"少收"完全颠倒。
4. 结算金额要用**账单上的**手续费扣；若还扣了保证金、退款，应在本表显式列示。
5. 要么明细行漏了渠道，要么合计行没跟着更新。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 费率超出 0~5% 合理区间检测
- 固定费为负检测
- 结算金额为负或超过交易金额检测
- 差异超过给定阈值检测（阈值由入参 tolerance 给出，默认 0.01 元）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 边界（请务必知道）

材料不足时**不给结论**，也不会输出「未发现问题」。
