# 物业公共能耗分摊核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：物业公共能耗分摊核对表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 这个免费版查什么

引擎 `CHECKS_GIVEN` 里的 6 项，本版本全部执行：

1. **分摊额复算**：分摊额 = 公共能耗总额 × 分摊比例（比例列空着时：分摊基数 × 分摊单价）
2. **分摊额合计 = 公共能耗总额**：全表分摊额合计 = 各组（期间 + 费用项目）公共能耗总额之和，总额按组去重只算一次
3. **合计行逐列复核**：合计行各列 = 明细行相加（公共能耗总额按组去重后相加）
4. **同一业主/单元重复行检测**：同一期间、同一费用项目下同一户出现两行
5. **空白与占位符检测**：必需列（期间 / 总额 / 业主单元 / 基数 / 单价 / 分摊额）为空或「待填」这类占位符
6. **金额或比例为负检测**：总额、基数、单价、比例、分摊额为负

材料不足（缺必需列 / 只有表头 / 正文为空）时**不给结论**，会列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. **总额只填在每组第一行**：Excel 合并单元格复制出来只有第一行有值，其余行是空的 ——
   那些行认不出本组总额，只能退回按「基数 × 单价」算，等于有一半的检查没做。
   取消合并、把总额**在每组每一行都填上**。
2. **单位混着来**：照明按「元/㎡」、电梯按「元/户」，却填在同一列里；或者把总额填进了单价列、
   把单价填进了分摊额列 —— 分摊额复算当场就对不上，而且对不上的是量级。
3. **比例与金额两条口径打架**：比例列写 50%，分摊额却是按 60% 算的；或者同一列里
   有人填「50」有人填「50%」（本工具都按 50% 认，但表里两种写法并存说明口径没统一）。
4. **一户拆成两行**：既有「分摊」行又补一行「调整」行，户号重复；红字冲减直接在本期填负数 ——
   重复行会把这一户的金额计两遍，负数会污染合计。调整与冲减要单独列示并在备注里说明。
5. **合计行手打**：明细改了合计行没跟着改；或者把每组重复填的同一个总额**按行数加了 N 遍**，
   总额被放大成倍数。合计行是公示与入账的取数口径，它错了两边都不可信。
