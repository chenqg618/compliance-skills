## 什么时候用

**谁会在什么时候用**：**有联营/合营企业的公司财务与合并报表岗**，在**月度/年度权益法核算与审计之前**：

- 期末账面价值 = 期初 + 投资收益 + 其他综合收益 + 其他权益变动 − 宣告分红 + 新增投资；
- 本期投资收益 = 被投资方净利润 × 持股比例；
- 持股比例 > 50% 就不该再走权益法（应纳入合并范围）。

## 这个免费版查什么

1. **合计行逐列复核**（期初 / 投资收益 / 其他综合收益 / 其他权益变动 / 宣告分红 / 新增投资 / 期末）；
2. **权益法滚动关系**（期末 = 期初 + 各增减项，P0）；
3. **本期投资收益 = 被投资方净利润 × 持股比例**（P0）；
4. **持股比例 > 50% 却仍按权益法**（应纳入合并范围，P0）；
5. **本期宣告分红为负**检测（P1）；
6. **同一被投资单位重复行**检测；
7. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这些表里真的会有人这么填）

1. **把"被投资方净利润"当成"投资收益"**：权益法确认的是**份额**（净利润 × 持股比例），直接把净利润全额填进投资收益必然不平。
2. **宣告分红填成正数加进账面价值**：宣告分红是**减少**长期股权投资账面价值的，符号写反会让滚动关系整条错。
3. **其他综合收益/其他权益变动漏填**：被投资方有 OCI 变动时，投资方要按比例同步确认，漏填就滚不上。
4. **持股比例用"实缴比例"而非"股权比例"**：权益法按章程/工商的股权比例算，混用会算错份额。
5. **同一被投资单位分两行**（按投资批次）：会报重复行；同一被投资单位请合并成一行或在备注注明批次。

## 边界（请务必知道）

- **不做**会计判断：重大影响是否成立（是否派董事、参与决策）、是否该转成本法或金融资产，请按准则判断；
- **不代替**合并报表编制或出具鉴证意见，也不判断内部交易抵消；
- **不核对**被投资方财务报表的**真伪**，也不与业务系统逐行比对；
- **不读取**被投资方报表 / 财务系统 / 股权管理系统的导出文件——需要你先导出成文本贴进来；
- **不判断**权益法投资收益的税务处理（属于税务判断）。
