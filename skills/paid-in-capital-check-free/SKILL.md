# 实收资本与股东出资核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**公司财务与董秘/证券事务**，在**年度审计、工商年报、增资/股改、以及股权转让之前**。每个股东的"认缴 / 实缴 / 未缴 / 持股比例"必须能对上，资本公积与实收资本合计要与账面、验资报告、银行流水一致：

- 未缴出资额 = 认缴出资额 − 累计实缴出资额；
- 持股比例 = 该股东认缴出资额 ÷ 各股东认缴合计（合计必须 100%）；
- 实收资本 + 资本公积 = 认缴合计 − 未缴合计；实缴不许超过认缴。

## 这个免费版查什么

1. **合计行逐列复核**（认缴 / 累计实缴 / 本期实缴 / 未缴 / 实收资本 / 资本公积 / 银行进账）；
2. **未缴出资额 = 认缴 − 累计实缴**（最常错的一条，P0）；
3. **实缴不超过认缴**（P0）；
4. **持股比例与认缴出资额匹配**（误差 > 0.02 个百分点即报）；
5. **所有者投入勾稽：实收资本 + 资本公积 = 认缴合计 − 未缴合计**（P0）；
6. **同一股东重复行**检测；
7. **空白与占位符**检测（含必需列缺失）。

## 常见错法（这些表里真的会有人这么填）

1. **把"注册资本"当成"实收资本"**：注册资本是章程约定的认缴总额，实收资本是实际到账的部分，两者在未缴清前**不相等**。
2. **持股比例按"实缴"算**：比例是按**认缴**（章程约定）算的；按实缴算会在增资未缴清时全错。
3. **本期实缴与银行进账填成两个数**：这两个数在正常情形下应当一致或能解释（如跨行到账时点差），不一致会被点出来。
4. **累计实缴按"本期实缴"重复填**：累计是滚动值（上期累计 + 本期实缴），填错会让未缴出资额整列错。
5. **同一股东分两次粘贴**（增资时重复）：会报重复行；分次出资请合并成一行或在备注里注明。


## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 本期实缴出资额 ≠ 银行进账金额（本期出资没有对应进账 / 进账被记到别的期间）
- 未缴出资额为负（实缴超过认缴，通常伴随认缴或累计实缴填错）
- 各股东持股比例合计 ≠ 100%（比例与认缴口径至少有一处错）
- 单一股东持股 > 50% 提示（> 67% 时注明"绝对控股"，需确认章程/协议里的表决权安排）
- 累计实缴出资额为 0 的股东提示（认而未缴，需核对出资期限）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

## 边界（请务必知道）

- **不做**法律与工商判断：非货币出资评估、股权代持、出资期限是否符合章程，请按公司法与工商口径认定；
- **不代替**验资、审计或出具鉴证意见，也不判断股权转让价格是否公允；
- **不核对**银行回单、验资报告、工商档案的**真伪**，也不与工商登记信息逐条比对；
- **不读取**工商系统 / 银行流水 / 股权管理系统的导出文件——需要你先导出成文本贴进来；
- **不判断**出资相关事项的税务处理（印花税、股权转让所得税属于税务判断）。
