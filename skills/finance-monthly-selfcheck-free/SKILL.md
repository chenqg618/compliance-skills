# 财务月度自查包（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：分段财务核对材料的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

```bash
node scripts/run.mjs --sample                 # 先看样例
node scripts/run.mjs --input 你的材料.json     # 跑自己的材料
```

## 常见错法（用这个包时最容易出问题的地方）

1. **忘了写分段标记**：每段必须以 `=== 检查名 ===` 开头（本包支持：应付账款账龄 / 预缴企业所得税 / 差旅费标准 / 现金盘点差异 / 发票领用存）。没有标记的段落会被判"缺这一段"，**不会**被静默忽略。
2. **把不该合并的表混在一段里**：一段里只贴一张表（同一个引擎要求的列必须齐全），混贴会让该段报"材料不足"。
3. **只贴表头当"已经核过"**：只给表头会如实报材料不足；本包**不会**因为缺数据而说"没问题"。
4. **免费档以为能跑 5 段**：免费版只跑前 3 段，另外 2 段会列在"未执行的检查项"里——这是如实声明，不是出错。
5. **拿它当鉴证/申报结论**：它只做表内与表间的算术、勾稽核对，不判断政策适用、不替代鉴证与申报。
