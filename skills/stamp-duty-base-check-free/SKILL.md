## 常见错法（这张表里真的会有人这么填）

1. **用错税目**：把"租赁合同"按"买卖合同"的 0.03% 算（应为 0.1%）—— 完整档会按参考税率表提示档位不匹配。
2. **计税依据少填**：合同金额含税、申报时忘了把增值税单列剔除，或反过来把不含税金额当依据 —— 两边口径必须写清。
3. **只登记已缴的合同**：漏登记的合同在台账上根本看不见，**"未申报"要靠合同金额 > 0 而依据 = 0 才能被发现**，所以合同台账要全。
4. **同一合同拆成多行（补充协议）却不标主合同号**：会报"同一合同编号出现多行"，请用"主合同号-补充1"区分。
5. **签订日期写成"去年三月"**：印花税按书立时点确定纳税义务期，日期要能解析（2026-01-15 / 2026年1月15日）。
