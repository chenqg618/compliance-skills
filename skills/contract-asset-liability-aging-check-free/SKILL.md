# 合同资产与合同负债账龄核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**建造/软件/服务类公司的项目财务**，在**月度结账与报表列示之前**：

- 期末合同资产 = 期初 + 本期新增 − 本期结转收入；
- 期末合同负债 = 期初 + 本期新增 − 本期确认收入；
- 同一合同不应**同时**挂合同资产与合同负债（应重分类）；账龄要与余额匹配。

## 这个免费版查什么

1. **合计行逐列复核**（合同资产与合同负债共 8 个金额列）；
2. **期末合同资产滚动关系**（P0）；
3. **期末合同负债滚动关系**（P0）；
4. **同一合同同时有合同资产与合同负债余额**（应重分类，P1）；
5. **账龄天数为负**（P1）；
6. **合同编号重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论并报「列缺失」）。

## 常见错法（这些表里真的会有人这么填）

1. **把"已开票未收款"当合同资产**：合同资产是**已履约未到期收款权**，与应收票据/账款不同，混列会让列示错。
2. **同一合同两边都有余额却不重分类**：合同资产与合同负债在同一合同上应对冲列示，否则报表两头虚增。
3. **确认收入用"开票金额"**：合同负债转收入要按**履约进度**，按开票会让滚动关系与收入确认口径全错。
4. **账龄填"合同开始日至今"**：账龄要按**该笔余额形成日**算，用合同开始日会让长期合同看起来账龄异常长。
5. **新增但账龄填 0/空**：完整档会提示——新增余额也要有形成日，否则账龄分析无法复核。

## 边界（请务必知道）

- **不做**会计判断：合同资产/负债的列示口径、履约进度与收入确认时点，请按准则与业务实质判断；
- **不代替**审计程序或出具鉴证意见，也不判断合同变更与索赔处理；
- **不核对**合同、验收单、发票的**真伪**，也不与项目系统逐行比对；
- **不读取**项目管理系统 / 合同系统 / 财务系统的导出文件——需要你先导出成文本贴进来；
- **不判断**合同资产减值的计提（属于会计估计）。
