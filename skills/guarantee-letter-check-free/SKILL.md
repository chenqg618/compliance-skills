# 保函台账与到期失效核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：建筑/外贸/制造企业的资金与授信管理岗，**每月做资金与授信管理时**都要把这张银行保函台账核一遍 —— 保函到期忘了注销会白占授信额度、该续期没续期会违约、保证金比例算错会多占资金。

**这张表会逐项核对什么**：
· 保函金额 = 合同金额 × 保证金比例（逐笔复算）
· 到期日 = 开立日 + 保函期限月数（按自然月对齐、月末回退）
· 保函号唯一性；关键字段空缺与占位符；保函金额非正；保函期限月数非正
· 状态与注销日期自洽；已过到期日仍未注销（额度还占着）逐笔点出

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

**基准日口径（重要）**：本工具判断"是否已过到期日"用的基准日是**台账内最新的一行开立日**（= 这张台账最后更新的时候），**不取本机当天** —— 同一份输入在任何一天复算，得到的结论完全一样。

## 这个免费版查什么

**免费档逐笔执行这 8 项**（跑 `--sample` 会打印实际执行了哪些）：

1. **保函金额与比例复算**：保函金额 = 合同金额 × 保证金比例（容差 1 分）。
2. **有效期复算**：到期日 = 开立日 + 保函期限月数（自然月对齐、月末回退，例如 1 月 31 日开立、期限 1 个月 ⇒ 2 月 28 日）。
3. **同一保函号出现多行**：一笔保函只能记一次。
4. **关键字段缺失或占位符**：必需列空着或写成 `-`、`待补`、`无`、`不适用` 都会被点出来（"注销日期"没注销时留空是对的，不算缺失）。
5. **保函金额非正**：金额 ≤ 0 即报。
6. **保函期限月数非正**：期限 ≤ 0 即报。
7. **注销日期与状态不一致**：状态写已注销却没有注销日期，或填了注销日期状态还是"有效"。
8. **到期未注销仍占额度**：到期日已过基准日、注销日期为空、状态仍显示有效的，逐笔点出并给出逾期天数。

**本版不执行**（会如实列进 `scope.checks_not_run`，不会用默认值编结论）：到期排期清单、额度释放清单与合计、保函金额超过合同金额、保证金比例低于合同约定比例、同一合同多份保函、额度占用与保函金额不一致、额度占用与授信上限对比 —— 共 7 项，见下面「需要完整档时（可选）」。

## 常见错法（这张台账里真的会有人这么填）

1. **保函金额按含税合同金额乘比例，合同金额那列填的却是不含税价** —— 两个口径混用，逐笔复算就差一个税额；反过来也一样。
2. **展期换开的新保函沿用旧保函号记一行**（触发"保函号重复"），或者**新旧各记一行、旧的那份忘了注销**（变成同一合同同一类型两份保函、双倍占授信）。
3. **到期日按"开立日 + 365 天"硬加**，而不是按自然月对齐 —— 月末开立、跨 2 月的保函最容易和"开立日 + 期限"差一两天。
4. **保函已经退回/注销，只改状态不改注销日期**（或只填注销日期状态还是"有效"）—— 额度到底释放没释放就说不清，后面每一步额度判断都跟着错。
5. **已注销的保函"担保额度占用"没归零**，或者有效保函的额度占用填的是"保函金额 − 已释放金额" —— 授信看起来还很宽裕，实际早就超上限了。
6. **同一合同下几个标段/分期的保函金额加总填成一笔**，于是保函金额超过合同金额（也看不出是哪一笔超的）。
7. **基准日按本机当天理解** —— 本工具用的是台账内最新开立日；台账只更新到上个月，就会把"上月已到期未注销"的点算漏。
