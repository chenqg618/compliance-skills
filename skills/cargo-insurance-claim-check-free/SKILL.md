# 货运险投保与货损理赔核对（免费版）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 不联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：物流公司、货代、外贸企业的商务或财务，**每月与保险对账时**，
以及**每一次货损索赔立案与赔款到账时**，都要把货运险台账核一遍。

**为什么非核不可**：这张表是几条纯算术关系串起来的 ——
保费 = 投保金额 × 费率；应赔金额 = 定损金额 − 免赔额（负按 0）；理赔差额 = 应赔 − 实收；
投保比例 = 投保金额 ÷ 货值。任意一条填错，当期就**少收赔款或多付保费**。

**这个免费版逐票复算什么**（检查项由引擎的 `CHECKS_GIVEN` 导出，跑 `--sample` 会打印）：

- 保费 = 投保金额 × 费率
- 应赔金额 = 定损金额 − 免赔额（负数按 0）
- 理赔差额 = 应赔金额 − 实收理赔款
- 投保比例 = 投保金额 ÷ 货值
- 同一保单号重复检测
- 关键字段空缺、占位符与金额负值检测
- 合计行逐列复核（每一列的合计是否等于各行之和）

每条结论都带**原文行号**，可被第三方用同一份输入复算；
材料不足时**不给结论**，会明确列出还缺什么。

也可以直接把 Excel 里复制出来的文本存成文件。表头要能认出上面那几列；
认不出来时本工具**只报缺哪列，不给任何结论**。

## 常见错法（这张表里真的会有人这么填）

1. **费率填成万分号口径**：保单写 0.8‰ 的时候顺手填 0.8，保费会算成 10 倍；本列统一按百分数填（0.08 就是 0.08%）。
2. **定损金额没超过免赔额，却把应赔填成负数**：应赔是 `max(0, 定损 − 免赔额)`，负数会让理赔差额跟着错一整行。
3. **赔款分次到账，只填最后一笔**：实收理赔款要填**累计**到账数，否则差额凭空变小、少赔看不出来。
4. **投保金额与货值分开改**：改了货值忘了改投保金额（或反过来），投保比例这一列的勾稽立刻对不上。
5. **一张保单保多票货时整行复制**：保单号会在多行重复出现并触发重复检测；请把它列成保单明细并注明，别把整行复制。
6. **有定损金额却没填货损数量**：索赔要能对上"坏了多少件、定损多少钱"，数量空着复核时会被打回。
7. **合计行手工写死**：明细行增删后合计没跟着更新，逐列复核会直接报出差额。
