# 关联方资金占用与往来清理核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：**集团财务、董秘/证券事务与内审**，在**月度往来清理、年度审计与信息披露之前**。监管对**非经营性资金占用**盯得最紧：

- 期末余额 = 期初余额 + 本期增加 − 本期减少；
- 非经营性资金占用期末余额 > 0 必须说明并制定清理计划；
- 账龄、是否计息、清理计划都要能对得上。

## 这个免费版查什么

1. **合计行逐列复核**（期初 / 增加 / 减少 / 期末）；
2. **期末余额 = 期初 + 本期增加 − 本期减少**（P0）；
3. **期末余额为负**（P0）；
4. **期初与期末符号相反且金额未明显缩小**（往来性质可能填错，P1）；
5. **计息情况空白或占位符**（资金占用必须说明是否计息，P1）；
6. **关联方+往来性质重复行**检测；
7. **空白与占位符**检测（含必需列缺失，仍照常给结论）。

## 常见错法（这些表里真的会有人这么填）

1. **把"经营性往来"与"非经营性资金占用"混在一行**：性质不同、监管口径完全不同；非经营性占用必须单独列示并说明清理计划。
2. **用"本期减少"掩盖未清理**：借新还旧式的对冲会让期末余额看起来正常，本工具核的是**期末 = 期初 + 增加 − 减少**的算术关系，掩不掉。
3. **计息情况留空**：资金占用是否计息是必答项，留空会被报出来。
4. **账龄按"最近一笔"算**：账龄要按**最早未清偿余额**的日期算，按最近一笔会让长期占用看起来很短。
5. **同一关联方按往来科目拆多行却不区分性质**：会报重复行；请按"关联方 + 往来性质"拆清。


## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 往来性质为「非经营性资金占用」且期末余额 > 0 检测（监管重点，应制定清理计划，报 P1）
- 账龄天数 > 365 天检测（长期未清理，报 P1）
- 期末余额 > 期初余额 + 本期增加 检测（逻辑不可能，报 P0）
- 清理计划为空白或占位符检测（报 P2）
- 计息情况为「不计息」且期末余额超过 1000 万提示（大额无偿占用，报 P2）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 使用次数与完整档

本免费版每次运行结束后会向服务端做**一次匿名次数统计**：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），**不发送你的材料、不写任何文件**。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；
· 第 4 次起：服务端会返回一段**完整档说明**（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；
· 统计不可用（离线/超时/被拦截）时什么都不做，**核对结果与退出码不受任何影响**。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。
