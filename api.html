按次调用的能力 API（公网 IP 直接可用）

入口：http://110.40.221.75 —— 不需要域名、与域名备案无关（备案只影响域名这个好看的主机名）。

怎么用（三步）

# 1) 先看有哪些能力（免费，无需凭证）
curl -s http://110.40.221.75/api/v1/capabilities

# 2) 免费端点：不需要付款、不需要注册，直接 POST（每项能力每天每 IP 有次数上限）
curl -s -X POST -H 'Content-Type: application/json' \
  -d '{"text":"银行\n2026-05-08 -1240.00 酒店消费\n账面\n2026-05-08 -1240.00 差旅报销"}' \
  http://110.40.221.75/api/v1/bank-reconciliation/free

# 3) 收费端点：直接 POST ⇒ 返回 HTTP 402 Payment-Needed（含价格与订单号）
#    按 402 账单完成支付后，带支付凭证重试同一请求即可（每次调用单独结算）
curl -i -X POST -H 'Content-Type: application/json' -d '{"text":"…"}' \
  http://110.40.221.75/api/v1/bank-reconciliation

支付流程（402 协议）

  1. POST 收费端点 → 402 + code: Payment-Needed + price + outTradeNo；
  2. 按账单完成支付（支付宝）；
  3. 携带支付凭证重试同一个请求 ⇒ 返回完整结果。

免费端点与收费端点是**同一套规则**的两档：免费档执行部分检查项，收费档执行全部并给出跨样本比对与统一整改清单。 先把免费档跑通、确认有用，再按次付费——不订阅、不包月。
