# compliance-agent —— 把一个文件夹交给它，自动分派检查、出整改清单

一个**本地智能体**：你不需要告诉它"哪份文件该查什么"，它自己判断每份材料是什么、
该跑哪些确定性检查，然后**合成一份跨材料的整改报告**。

**完全离线**：不联网、不外发材料、不需要 API Key；每一处结论都由**确定性引擎**算出，可复算。

## 与 MCP server 的区别

| | 谁决定调什么 | 适合 |
|---|---|---|
| `mcp-compliance-server` | **外面的 Agent** 决定调哪个工具 | 已经在用 Claude Desktop / Cursor 等 |
| `compliance-agent`（本目录） | **它自己**分派，并汇总成一份报告 | 手里有一叠材料，想一次过一遍 |

## 用法

```bash
node agent.mjs --dir ./materials          # 扫目录下所有 .txt/.md/.csv/.json
node agent.mjs --file 报价.txt --file 合同A.txt --file 合同B.txt
node agent.mjs --sample                   # 看一份示例报告
node agent.mjs --dir ./materials --json   # 机器可读
```

它会为每份材料判断类型（报价单 / 合同 / 票据 / 外贸单证 / 三单匹配 / 报销 / 银行对账 / 广告文案 / 招投标材料），
命中哪些关键词也会**如实打印**；**识别不出来就说识别不出，不会硬套一个检查**。

**两份以上合同会自动额外做一次横向比对**（找出"同一模板下哪一份被改过"）。

## 报告里一定会有三样东西

1. **每处结论的原文出处**（行号 + 命中内容），你可以自己复核；
2. **本次执行的检查项** —— 说明结论覆盖了什么范围；
3. **本次没有执行的检查项** —— 所以「没报问题」**不等于**「没有问题」。

## 边界（**它不做的事**）

- 不判断该不该付款、哪份文件更有利、是否违法 —— 那是人 / 法务的判断；
- 不给法律、税务或审计意见；
- **不做 OCR**：扫描件/图片要先转成文字（只吃 `.txt/.md/.csv/.json`）；
- 不联网查任何外部数据；
- 材料不足时不给结论。

## 依赖

引擎与 `../mcp-compliance-server/scripts/engines/` **共用同一份**（同仓库、同一次发布一起出去），
所以两个目录要一起下载。只用 Node 标准库，**无需安装任何依赖**（Node ≥ 18）。
