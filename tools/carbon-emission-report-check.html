碳排放报告数据核对（免费版）

完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 核对过程不需要联网、不需要 API Key、没有调用次数上限。

什么时候用

谁会在什么时候用：纳入全国碳市场的重点排放单位的能源 / 安环 / 财务岗位，

在每年编制年度温室气体排放报告之后、第三方核查进场之前（迎检阶段）；

以及核查意见退回后重新报数之前。集团对下属企业报表做汇总时也用同一口径先自查一遍。

为什么必须核：报告里的排放量是「活动数据 × 排放因子 × 氧化率」逐项算出来的，

再汇总到分设施 / 分范围（范围一 直接排放、范围二 间接排放）。核查机构会逐格复算，

算不平就要退回重报，编制与迎检的时间被反复消耗，配额清缴也挂在同一套数字上。

这些格子完全可机械复算 —— 所以值得在自己这边先算一遍。

这张表会怎么核：把报告的明细表（含表头）从 Excel 复制成文本贴进来即可，

Tab 分隔最稳；每一行要有 行类型 / 设施名称 / 报告年度 / 范围 / 能源品种 / 活动数据 /

活动数据单位 / 活动数据折算（MWh）/ 排放因子 / 排放因子单位 / 氧化率 / 排放量（tCO2e），

小计与合计行用「行类型」列标出来（小计 / 合计）。

每条结论都带原文行号与出处（具体到「第 N 行」与那一格的数字），可被第三方用同一口径复算；

材料不足（缺必需列 / 空文本 / 认不出表头）时不给结论，会明确列出还缺什么 ——

既不说「一致」，也不说「不一致」。

这个免费版查什么（6 项）

  1. 单项排放量复算：逐行 活动数据 × 排放因子 × 氧化率 = 排放量（tCO2e），容差 0.01 tCO2e。
  2. 分设施/分范围合计勾稽：小计行与合计行必须等于其对应明细之和 —— 逐列复核

「活动数据」与「排放量（tCO2e）」两列（活动数据列仅在该组明细单位一致时复核）。

  1. 间接排放（范围二）单位换算勾稽：万kWh=10MWh、kWh=0.001MWh、GJ=1/3.6MWh，

折算结果必须与「活动数据折算（MWh）」列一致；认不出的单位单列一条、不给结论。

  1. 重复行检测：同一设施 + 同一能源品种 + 同一报告年度只应有一行（跨年度出现不算重复）。
  2. 排放因子引用一致性：同一能源品种（同一排放因子单位）在不同行用了不同因子值即报出，

并给出两处原文。

  1. 必需字段检测：空白 / 占位符（无、待填…）/ 认不出格式 / 为负 / 氧化率越界；

缺必需列只报「材料不足」，绝不给结论。

本免费版不含完整档的 5 项检查（下面「边界」里如实列出）。

检查项以引擎导出的 CHECKS_GIVEN / CHECKS_WITHHELD 为唯一来源，跑 --sample 会打印实际执行了哪些。

使用次数与完整档

本免费版会在本包目录里记一个使用次数（scripts/.hint-count，一个整数，不含任何机器或用户信息）。

· 前 3 次：完全离线（不发生任何网络请求），输出与现在完全一样；

· 第 4 次起：服务端会返回一段完整档说明（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；

· 第 4 次起才会向服务端问一次（只发包标识与次数），拿回完整档说明；

· 请求不可用（离线/超时/被拦截）时什么都不做，核对结果与退出码不受任何影响；

· 不想要这次统计可以加 --no-stats（核对功能完全不受影响，只是拿不到完整档说明）。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

需要完整档时（可选）

本免费版是完整可用的核心产出，本版本不包含下面这些项：

  • 与上一年度报告对比（同类设施/品种排放量变化超 ±20% 提示，并给本年度与上年度两处原文）
  • 排放因子与官方缺省值/实测值口径不一致检测（写「实测值」取值就是官方缺省值，或写「缺省值」但数值与官方缺省值不符）
  • 配额（分配量）与实际排放量对比（缺口/盈余吨数与需清缴量；同设施同年度配额填了不同值一并报出）
  • 跨期/跨版本不一致检测（同一报告年度出现多个报告版本、同一版本跨多个年度、同设施同品种数据来源跨年度不一致）
  • 分设施×分范围汇总清单（按差异吨数从大到小排序，逐条给出可整改动作 consolidated_actions）

同名工具的完整档是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别就是上面这些，没有别的。

常见错法（年度排放报告里最常见的 5 个）

  1. 活动数据单位不统一：同一张表里混用万 kWh 与 MWh、GJ 与 MWh，边界处最容易错一个数量级。
  2. 氧化率漏乘：只有部分燃料需要氧化率，漏乘会让排放量系统性偏低。
  3. 同一能源品种用了两个排放因子：一处抄缺省值、一处抄实测值，核查机构一定会问。
  4. 范围一/范围二混填：外购电力的间接排放填进范围一，分范围合计就永远对不上。
  5. 只核总量不核分设施：分设施合计 ≠ 总量时，报告整体会被退回重报。

口径说明：工具只做报告表内的复算与勾稽，不判断排放因子是否应当采用实测值、也不做核查结论。

材料不足时不给结论。

本工具不做引擎 CHECKS_OUT_OF_SCOPE 里列的那些判断：不判定报告是否满足主管部门的

核查技术规范、不判定参数（因子 / 氧化率 / 低位发热量）选取是否恰当、不核活动数据的真实性、

不读 .xlsx/.pdf 原件、核对过程核对过程核对过程不联网取官方缺省值与配额文件。

材料不足时不给结论，也不会输出「未发现问题」。

① 与上一年度报告对比（同类设施/品种变化超 ±20%）；② 排放因子与官方缺省值/实测值口径核对；
