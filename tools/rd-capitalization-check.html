什么时候用

谁会在什么时候用：有研发投入的企业（尤其高新与拟上市），在**每月归集研发支出、

以及年度汇算与审计之前**：

  • 本期发生额 = 资本化金额 + 费用化金额；
  • 期末无形资产余额 = 累计资本化金额 − 累计摊销额；
  • 本期摊销额 ≈ 累计资本化金额 ÷ 摊销月数（直线法，偏离超 5% 提示）。

研究阶段应费用化、开发阶段才可能资本化——审计与税务都会盯着这几列，而它们全都能算出来对错。

这个免费版查什么

  1. 合计行逐列复核（发生额 / 资本化 / 费用化 / 累计资本化 / 累计摊销 / 本期摊销 / 期末余额）；
  2. 本期发生额 = 资本化金额 + 费用化金额（最常错的一条）；
  3. 期末无形资产余额 = 累计资本化金额 − 累计摊销额；
  4. 资本化金额或费用化金额为负检测；
  5. 本期摊销额为负检测；
  6. 同一项目同一阶段重复行检测；
  7. 空白与占位符检测（含必需列缺失）。

常见错法（这些底稿里真的会有人这么填）

  1. 把研究阶段的支出也填进"资本化金额"：研究阶段必须费用化；完整档会直接点出来。
  2. 发生额只填资本化那部分：本期发生额是全部研发支出，资本化 + 费用化必须等于它，否则第 2 条就红。
  3. 累计资本化按"本期资本化"重复填：累计是滚动值（上期累计 + 本期资本化），填错会让期末余额整列错。
  4. 摊销月数填 0 却又有本期摊销额：摊销月数是摊销期限，0 会让直线法校验跳过、也可能暴露口径混乱。
  5. 同一项目分阶段各贴一行却写同一个阶段名：会报重复行；不同阶段请如实写"研究阶段/开发阶段"。
