研发支出资本化与费用化划分核对（免费版）

完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 核对过程不需要联网、不需要 API Key、没有调用次数上限。

什么时候用

谁会在什么时候用：有研发投入的企业（尤其高新与拟上市），在**每月归集研发支出、

以及年度汇算与审计之前**：

  • 本期发生额 = 资本化金额 + 费用化金额；
  • 期末无形资产余额 = 累计资本化金额 − 累计摊销额；
  • 本期摊销额 ≈ 累计资本化金额 ÷ 摊销月数（直线法，偏离超 5% 提示）。

研究阶段应费用化、开发阶段才可能资本化——审计与税务都会盯着这几列，而它们全都能算出来对错。

这个免费版查什么

  1. 合计行逐列复核（发生额 / 资本化 / 费用化 / 累计资本化 / 累计摊销 / 本期摊销 / 期末余额）；
  2. 本期发生额 = 资本化金额 + 费用化金额（最常错的一条）；
  3. 期末无形资产余额 = 累计资本化金额 − 累计摊销额；
  4. 资本化金额或费用化金额为负检测；
  5. 本期摊销额为负检测；
  6. 同一项目同一阶段重复行检测；
  7. 空白与占位符检测（含必需列缺失）。

常见错法（这些底稿里真的会有人这么填）

  1. 把研究阶段的支出也填进"资本化金额"：研究阶段必须费用化；完整档会直接点出来。
  2. 发生额只填资本化那部分：本期发生额是全部研发支出，资本化 + 费用化必须等于它，否则第 2 条就红。
  3. 累计资本化按"本期资本化"重复填：累计是滚动值（上期累计 + 本期资本化），填错会让期末余额整列错。
  4. 摊销月数填 0 却又有本期摊销额：摊销月数是摊销期限，0 会让直线法校验跳过、也可能暴露口径混乱。
  5. 同一项目分阶段各贴一行却写同一个阶段名：会报重复行；不同阶段请如实写"研究阶段/开发阶段"。

需要完整档时（可选）

本免费版是完整可用的核心产出，本版本不包含下面这些项：

  • 研究阶段却有资本化金额检测（研究阶段支出应费用化）
  • 开发阶段但资本化金额为 0 提示（可能该资本化而未资本化）
  • 本期摊销额与直线法（累计资本化 ÷ 摊销月数）偏离超过 5% 提示
  • 资本化金额超过本期发生额检测
  • 期末无形资产余额为负检测

同名工具的完整档是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别就是上面这些，没有别的。

使用次数与完整档

本免费版每次运行结束后会向服务端做一次匿名次数统计：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），不发送你的材料、不写任何文件。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；

· 第 4 次起：服务端会返回一段完整档说明（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；

· 统计不可用（离线/超时/被拦截）时什么都不做，核对结果与退出码不受任何影响。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

边界（请务必知道）

  • 不做会计判断：研发阶段怎么划分、某笔支出该不该资本化需专业论证并与审计确认；
  • 不判断研发费用加计扣除的归集口径与优惠资格（见同系列「研发费用加计扣除归集核对」）；
  • 不代替审计程序、不出具鉴证意见，也不判断资本化时点是否恰当；
  • 不读取研发项目管理系统 / 工时系统 / 财务系统的导出文件——需要你先导出成文本贴进来；
  • 不判断无形资产摊销年限是否合理（只核你给的摊销月数与摊销额之间的算术关系）；
  • 材料不足（认不出表头、没有数据行、必需列缺失）时不给结论，只告诉你还缺什么。
