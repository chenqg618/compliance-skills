关联方资金占用与往来清理核对（免费版）

完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 核对过程不需要联网、不需要 API Key、没有调用次数上限。

什么时候用

谁会在什么时候用：集团财务、董秘/证券事务与内审，在月度往来清理、年度审计与信息披露之前。监管对非经营性资金占用盯得最紧：

  • 期末余额 = 期初余额 + 本期增加 − 本期减少；
  • 非经营性资金占用期末余额 > 0 必须说明并制定清理计划；
  • 账龄、是否计息、清理计划都要能对得上。

这个免费版查什么

  1. 合计行逐列复核（期初 / 增加 / 减少 / 期末）；
  2. 期末余额 = 期初 + 本期增加 − 本期减少（P0）；
  3. 期末余额为负（P0）；
  4. 期初与期末符号相反且金额未明显缩小（往来性质可能填错，P1）；
  5. 计息情况空白或占位符（资金占用必须说明是否计息，P1）；
  6. 关联方+往来性质重复行检测；
  7. 空白与占位符检测（含必需列缺失，仍照常给结论）。

常见错法（这些表里真的会有人这么填）

  1. 把"经营性往来"与"非经营性资金占用"混在一行：性质不同、监管口径完全不同；非经营性占用必须单独列示并说明清理计划。
  2. 用"本期减少"掩盖未清理：借新还旧式的对冲会让期末余额看起来正常，本工具核的是期末 = 期初 + 增加 − 减少的算术关系，掩不掉。
  3. 计息情况留空：资金占用是否计息是必答项，留空会被报出来。
  4. 账龄按"最近一笔"算：账龄要按最早未清偿余额的日期算，按最近一笔会让长期占用看起来很短。
  5. 同一关联方按往来科目拆多行却不区分性质：会报重复行；请按"关联方 + 往来性质"拆清。

需要完整档时（可选）

本免费版是完整可用的核心产出，本版本不包含下面这些项：

  • 往来性质为「非经营性资金占用」且期末余额 > 0 检测（监管重点，应制定清理计划，报 P1）
  • 账龄天数 > 365 天检测（长期未清理，报 P1）
  • 期末余额 > 期初余额 + 本期增加 检测（逻辑不可能，报 P0）
  • 清理计划为空白或占位符检测（报 P2）
  • 计息情况为「不计息」且期末余额超过 1000 万提示（大额无偿占用，报 P2）

同名工具的完整档是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别就是上面这些，没有别的。

边界（请务必知道）

  • 不做法律与监管判断：是否构成资金占用、要不要披露、是否触发监管措施，请按法规与专业意见认定；
  • 不代替审计程序或出具鉴证意见，也不判断关联交易定价是否公允；
  • 不核对银行流水、合同、决议文件的真伪，也不与资金系统逐行比对；
  • 不读取资金系统 / 往来管理系统 / 银行流水的导出文件——需要你先导出成文本贴进来；
  • 不判断资金占用的税务与信息披露后果（属于税务与证券合规判断）。
