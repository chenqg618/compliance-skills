什么时候用

谁会在什么时候用：HR / 薪酬岗与员工本人，在每年 3~6 月个税年度汇算（综合所得）期间：

  • 应纳税所得额 = 全年工资薪金 + 劳务报酬 − 减除费用 − 专项扣除 − 专项附加扣除 − 其他扣除（为负按 0）；
  • 全年应纳税额 = 应纳税所得额 × 适用税率 − 速算扣除数（年度七级超额累进）；
  • 应补(退)税额 = 全年应纳税额 − 已预缴税额。
与已有产品的区别：iit-withholding-check 核月度累计预扣；payroll-withholding-reconcile 核 工资表代扣 vs 申报数；本产品核年度汇算这一张表（含税率档位与速算扣除数是否匹配）。

这个免费版查什么

  1. 合计行逐列复核（收入/各项扣除/应纳税所得额/应纳税额/已预缴/应补退；税率与速算扣除数不合计）；
  2. 应纳税所得额 = 收入 − 各项扣除（为负按 0，P0）；
  3. 全年应纳税额 = 应纳税所得额 × 税率 − 速算扣除数（P0）；
  4. 应补(退)税额 = 全年应纳税额 − 已预缴税额（P0）；
  5. 应纳税所得额为负（未按 0 处理，P1）；
  6. 员工编号重复行检测；
  7. 空白与占位符检测（含必需列缺失，仍照常给结论并报「列缺失」）。

常见错法（这些表里真的会有人这么填）

  1. 应纳税所得额为负却按负值算税：为负要按 0 处理，否则会算出负数税额。
  2. 用月度预扣率表算年度汇算：年度汇算是年度七级超额累进（与月度预扣表不同），用错档位税额就错。
  3. 专项附加扣除填成"年度总额 ÷ 12"：汇算表按年度合计填，填成月额会少扣 11 个月。
  4. 劳务报酬直接按收入额进综合所得：劳务报酬要按收入减除 20% 费用后的余额计入，直接填收入会多算税基。
  5. 应补(退)填成正数表示退税：本工具按"正数=应补、负数=应退"核对，符号写反会被直接点出来。
