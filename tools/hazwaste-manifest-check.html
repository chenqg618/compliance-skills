危险废物转移联单与台账核对（免费版）

完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 核对过程不需要联网、不需要 API Key、没有调用次数上限。

什么时候用

危险废物（HW 类）产生单位每月（每季）结账前，以及每年在固体废物管理信息系统做上年度申报之前，

财务、安环、危废管理员必须把三套材料对一遍：危险废物管理台账、危险废物转移联单（电子/纸质）、

以及贮存与出入库记录、处置合同结算。按《固体废物污染环境防治法》，管理台账、转移联单、

危险废物管理计划都是法定义务，年度申报要填上一年度的产生量、贮存量、转移量与利用处置量 ——

数量或金额对不上就要查，错报、漏报会被处罚，报错了还要更正申报。

具体该在哪些时刻跑这个工具：

  • 每月（每季）结账前：台账上每一类废物的「期初贮存 + 本期产生 − 本期转移 = 期末贮存」要能算平；
  • 拿到联单回单后：同一张联单，台账上的转移量要与联单上的转移量一致，

联单金额要与「处置单价 × 数量 + 运费 + 包装费」一致；

  • 做完一批转移后：联单号是唯一凭证，同一联单号在台账里出现两次，往往意味着同一次转移被记了两遍

（转移量和金额都翻倍，年度申报的量也会跟着虚高）；

  • 从 Excel 导出台账后：导出的表常带一行「合计」，它的每一列（包括期初/期末贮存，不只是金额）

都要等于明细之和；

  • 年度申报填报前：先把上面这些核干净 —— 申报数据就是从台账和联单来的。

这些格子都能手算复现，所以本工具把它做成确定性核对：每条结论都带原文行号与具体数字，

可被第三方用同一口径复算；材料不足时不给结论。

这个免费版查什么（只执行下面 6 项）

  1. 产生量与贮存量勾稽：逐行复算 期初贮存 + 本期产生 − 本期转移 = 期末贮存，差额不为零即列出差额。
  2. 转移联单与台账的数量一致性：同一联单号，台账本期转移合计 = 联单转移量合计。
  3. 转移联单金额勾稽：联单转移量 × 处置单价 + 运费 + 包装费 = 联单金额（含运费/包装费时按列勾稽）。
  4. 同一联单号重复登记：联单号在本表内必须唯一，出现两次以上即列出（可能重复计转移量）。
  5. 合计行逐列复核：合计行每一列 = 明细之和，贮存列也要对，不是只核金额。
  6. 必需字段缺失与数值格式检测：废物类别、废物代码、单位、期初贮存、本期产生、本期转移、期末贮存、

联单号、转移量、处置单价、联单金额，空白/占位符/认不出的数值逐处点名。

这个免费版不包含（5 项，如实列出，本版本不执行）

  1. 管理计划与执行量对比（计划转移量 vs 实际转移量，超计划提示）；
  2. 危险废物贮存超期检测（期末仍有贮存、且按入库日期算已超过一年）；
  3. 跨期归属检测（联单日期不在本期统计期间内）；
  4. 接收单位合同单价一致性（同一接收单位在不同联单上单价不一致）；
  5. 分废物类别 × 接收单位的汇总清单（按差额排序、给出可整改动作）。

上面 5 项在本版本里一项都不会执行，也不会被伪造出来；跑 --sample 会打印实际执行了哪些。

需要完整档时（可选）

本免费版是完整可用的核心产出，本版本不包含下面这些项：

  • 管理计划与执行量对比（按废物类别汇总 计划转移量 vs 本期实际转移量，超出计划即提示）
  • 危险废物贮存超期检测（期末仍有贮存的，按入库日期与统计截止日期判断是否超过一年）
  • 跨期归属检测（联单日期不在统计期间内的，单独列出）
  • 接收单位合同单价一致性（同一接收单位在不同联单上处置单价不一致即列出）
  • 分废物类别 × 接收单位的汇总清单（按差额从大到小排序，给出可整改动作）

同名工具的完整档是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别就是上面这些，没有别的。

常见错法（每月台账里最常见的 5 个）

  1. 把"联单量"当"台账量"填：联单是运输凭证、台账是内部记录，两者必须逐单号对上；只填一边就等于没核。
  2. 期初贮存直接抄上月期末：上月改过账就会断链；工具用「期初 + 产生 − 转移 = 期末」独立复算，抄数会被抓出来。
  3. 同一张联单登记两次：跨月重复录入最常见（补录 + 原录入都在），会把转移量算重。
  4. 运费/包装费漏进联单金额：处置单价 × 数量只是"处置费"，含运费的联单金额要按列一起勾稽。
  5. 只填类别不填废物代码：管理计划是按代码考核的，缺代码就无法与计划对比（完整档会报出来）。

口径说明：工具只核表内与联单之间的算术与勾稽，不判断废物类别是否分类正确、也不判断处置单位资质是否有效

（那属于环保部门与合同审查）。材料不足时不给结论，会明确列出缺哪些列。

边界（请务必知道）

本工具不做引擎 CHECKS_OUT_OF_SCOPE 里列的那些判断：不判定废物是否真的属于所填 HW 类别、

不判定产生/贮存/转移是否真实合规、不核验接收单位资质真伪（核对过程核对过程核对过程不联网）、不替代管理计划备案与法定申报手续、

不读 .xlsx / .pdf 原件。材料不足时不给结论，也不会输出「未发现问题」。
