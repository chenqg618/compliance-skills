银行流水对账核对（免费版）

一句话：把银行流水和企业账面记录贴成两段，逐笔配对、列出两侧未达账项 —— 不需要付款，也不需要注册。

完全免费：不需要付款、不需要注册、不需要配置任何 API Key，直接调用即可。

什么时候用

  • 每月末对账：银行流水和企业账对不上，想知道到底是哪几笔
  • 想知道银行有、账上没有的有哪些（漏记、手续费、利息、跨月入账）
  • 想知道账上有、银行没有的有哪些（已开出未收、在途未达、跨期）
  • 怀疑某一笔被重复录入了两次

这个免费版查什么

#检查项
1逐笔自动配对：金额相等 且 日期相差不超过 3 天
2未达账项清单：银行有账上无 / 账上有银行无（含笔数与合计）
3单侧重复记录检测（同日期同金额出现两次以上）
4两侧笔数与金额合计的对比表

金额会做归一化：1,240.00、1240、-¥1,240.00、(1,240.00) 都被认成同一个数，

不会因为写法不同就报错。摘要文字不参与配对 —— 只认金额和日期，避免被"写法不同"干扰。

这个免费版不包含

以下检查项不在本版本范围内，调用时也不会执行：

  • 可疑配对（金额相近但不相等，差在容差内 —— 常在手续费、汇差、笔误）
  • 疑似跨期未达（另一侧有同金额记录，但日期超出匹配窗口）
  • 对账恒等式校验（银行合计 − 账面合计 = 银行未达 − 账面未达）
  • 自定义匹配窗口与金额容差（dayWindow / toleranceAbs）
