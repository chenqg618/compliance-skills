试算平衡与期末结转核对（免费版）

完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 不联网、不需要 API Key、没有调用次数上限。

什么时候用

谁会在什么时候用：会计与财务主管在每月结账时、财务经理在每年审计进场前，

都要先把这张科目余额表（试算平衡表）核一遍 —— 账平了才能出报表、才能交给审计。

一笔借贷不平会带着错一路进到资产负债表和利润表，所以这是"每月必须做、且完全算得出来对错"的事。

这张表会逐项核对什么：

  • 资产负债类逐行复算：期末余额 = 期初余额 + 本期借方发生额 − 本期贷方发生额
  • 损益类期末结转为零：结转后期末余额必须为 0，且发生额列应是含结转分录的结转后口径
  • 借贷合计相等：期初余额合计、本期借方发生额合计与本期贷方发生额合计、期末余额合计
  • 明细账与总账勾稽：表里的合计行必须等于各一级科目行之和
  • 科目层级小计：上级科目 = 其直接下级科目之和（逐列复核）
  • 重复科目：同一科目编码出现多行
  • 空缺与非法值：必填列为空、占位符、非数字、科目类别无法识别

每条结论都带原文行号与出处，可被第三方用同一份输入复算；

材料不足时不给结论，会明确列出还缺什么。

与已有能力的区别：本工具核的是账套自己的试算平衡（科目余额表内部勾稽与期末结转）；

发票本身的一致性、增值税申报口径的进销项核算，都是另外的能力，不在本工具范围内。

材料怎么给

把科目余额表连同表头从 Excel 复制成文本贴进来（Tab 分隔最稳），列头要能认出

「科目编码 / 科目名称 / 科目类别 / 期初余额 / 本期借方发生额 / 本期贷方发生额 / 期末余额」。

金额口径（务必一致）：借贷方向带符号 —— 借方余额为正、贷方余额为负；

本期借方、本期贷方两列都填正数；发生额列用结转后口径（含损益结转分录）。

常见错法（这张表里真的会有人这么填）

  1. 负债/权益余额填成正数：应付账款填 150000.00 而不是 -150000.00，

于是「期初 + 借 − 贷 = 期末」永远差两倍，期初合计也不可能为 0。贷方余额必须填负数。

  1. 发生额列只填业务发生额、不含期末结转分录：损益类科目本期借方 ≠ 贷方，

借贷合计当场不平 —— 请用"结转后"口径导出，借、贷两列都含结转分录。

  1. 一级科目行与明细行一起塞进表里又都计入合计：合计行把 1122 应收账款 和

1122.01 / 1122.02 加了两次，金额直接翻倍。要么只列一级科目，要么让上级行只当小计。

  1. 损益类余额留在表里不结转：管理费用期末还挂着 90000，说明期末结转分录没做；

损益类是"期末必然为 0"的科目，留在表里本身就是错。

  1. 只核"借方合计 = 贷方合计"就以为平了：期初余额合计、期末余额合计同样必须借贷相等，

只盯本期发生额会漏掉上期带下来的错。

  1. 用括号或带单位写负数：(1,000.00)、1,000.00元 都会解析不成数字；

请写成 -1000.00 这样的规范数字。
