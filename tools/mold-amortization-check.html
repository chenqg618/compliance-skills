模具与工装摊销核对（免费版）

完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 不联网、不需要 API Key、没有调用次数上限。

什么时候用

谁会在什么时候用：成本会计、财务主管在每月成本核算与结账之前，必须把模具与工装

（注塑模、冲压模、压铸模、检具、夹具、专用工装）的摊销台账核一遍才能往下走 ——

模具单体金额大，摊销额直接进当期产品成本与毛利，而这张表要和产量、剩余价值勾稽。

这张表会逐项核对什么：模具与工装摊销台账的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带原文行号与出处，可被第三方用同一口径复算；

材料不足时不给结论，会明确列出还缺什么。

这个免费版查什么

本版本执行 6 项：

  1. 本期摊销额复算：可摊销总额 ÷ 摊销总产量 × 本期产量 = 本期摊销额（产量法）
  2. 未摊销余额复算：可摊销总额 − 累计摊销 = 未摊销余额
  3. 合计行逐列复核：每一列分别与各明细行之和比对
  4. 同一模具编号重复行检测：同一模具编号 + 同一期间出现两行会被重复摊销
  5. 空白与占位符检测：可摊销总额 / 摊销总产量 / 本期产量 / 本期摊销额 / 累计摊销 / 未摊销余额等必需列
  6. 金额或数量为负检测：可摊销总额、产量、本期摊销额、累计摊销、单价为负

本版本不包含下面这些（完整版才做；这里如实列出，绝不会用默认值编造出结论）：

  • 累计摊销超过可摊销总额提示
  • 本期产量超过摊销总产量检测
  • 摊销总额为零却有摊销额检测
  • 未摊销余额为负检测
  • 摊销单价偏离参考区间（同表理论单价中位数 ±50%）提示

常见错法（这张台账最容易填错的 5 处）

  1. 把「可摊销总额」直接填成模具原值（没扣预计残值、没扣已确定的供应商返款）——

产量法下单价 = 可摊销总额 ÷ 摊销总产量，残值留在里面会让每期摊销偏大、

未摊销余额提前摊完。本工具只核台账内部勾稽，残值口径要你自己在这一列体现。

  1. 「摊销总产量」和「本期产量」两列填反 —— 两列都是数量、行里看不出错，

但单价会从 4.00 变成 40.00，本期摊销额整列偏大十倍。

表头请写全（摊销总产量 / 本期产量），工具是按表头认列的。

  1. 「累计摊销」填成上期累计（不含本期） —— 未摊销余额 = 可摊销总额 − 累计摊销，

这里的累计摊销必须含本期；只填上期数会让余额每期虚高一个本期摊销额。

  1. 同一副模具多期分行时，只在有的行填数、有的行留空或写「待填 / 暂估 / —」 ——

空白与占位符检测会逐行报出缺的是哪一列；占位符不算数，请先补齐或先删掉那一行。

  1. 合计行的第一列不写「合计」（写成「总合计」「汇总」，或把「合计」写到第 2 列）——

认不出合计行时它会被当成一条明细去复算，反而多出一堆假问题；

合计行请在第 1 列写「合计 / 总计 / 小计 / 共计」，且整张表只出现一次。
