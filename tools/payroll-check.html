工资表发放前核对（免费版）

一句话：发薪前把工资表算一遍 —— 不需要付款，也不需要注册。

完全免费：不需要付款、不需要注册、不需要配置任何 API Key，直接调用即可。

什么时候用

  • 每月发薪前，想确认每个人的实发是不是算对了（应发 − 社保 − 公积金 − 个税 − 其他扣款）
  • 想知道合计行是不是真的等于各列之和（合计错，银行代发总额就错）
  • 担心同一个人出现两行（重复发薪）
  • 想知道有没有实发空缺或还留着 【填写】、TBD 的行

这个免费版查什么

#检查项
1逐人算术：实发工资 = 应发工资 − 各项扣款之和
2合计行复核：合计行的每一列是否等于该列各人之和
3重复人员检测：同一姓名出现两行以上
4空白与占位符：实发工资空缺、【填写】/TBD 残留

按表头认列，不按列的位置 —— 各家的工资表列序都不一样，按位置认一定会认错。

金额写法做归一化（10,000.00、¥1,050.00、(100) 都能认）。

怎么用

node scripts/run.mjs --sample
node scripts/run.mjs --input my-payroll.json
node scripts/run.mjs --input my-payroll.json --json

入参：把工资表连表头一起贴进来（从 Excel 直接复制即可，Tab 分隔最稳）。

退出码

码含义
0已执行检查
1没给入参
3材料不足 —— 此时不给结论（认不出表头也不硬猜列）
4入参文件读不到或无法解析
9未预期错误

这个免费版不包含

  • 应发工资 = 各项加项之和（基本工资 + 绩效 + 补贴…）
  • 个税校验（按累计预扣税率表复核）
  • 实发合计与声明的银行代发总额是否一致
  • 扣款为负、实发为负等异常值提示
