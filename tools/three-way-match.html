三单匹配AI核对（免费版）

一句话：把采购订单、入库单、发票放在一起核一遍 —— 不需要付款，也不需要注册。

完全免费：不需要付款、不需要注册、不需要配置任何 API Key，直接调用即可。

什么时候用

  • 付款前想确认：订单号 / 供应商 / 物料在三张单据上是不是同一个
  • 担心数量或金额在订单、入库、发票之间对不上（这是多付/错付的常见来源）
  • 想查有没有同一张发票重复入账（重复付款线索）
  • 单据模板里还留着 【填写…】、XXX、TBD 没替换

这个免费版查什么

#检查项
1关键字段跨单据一致：采购订单号 / 供应商 / 物料
2数量 / 单价 / 金额跨单据一致
3重复发票号线索
4模板占位符残留

金额会做归一化：1,000.00 与 1000.00 视为同一个数，不会因为写法不同就报错。

只出现在一张单据里的字段不会报 —— 无从比对的事情我们不猜。

怎么用

node scripts/run.mjs --sample
node scripts/run.mjs --input my-match.json
node scripts/run.mjs --input my-match.json --json

入参两种写法，任选：

{ "documents": [
  { "type": "采购订单", "text": "采购订单号: PO-1\n供应商: 河南甲物资\n数量: 100\n金额: 1000.00" },
  { "type": "入库单",   "text": "采购订单号: PO-1\n供应商: 河南甲物资\n数量: 100\n金额: 1000.00" },
  { "type": "发票",     "text": "发票号: INV-1\n采购订单号: PO-1\n数量: 100\n金额: 1000.00" }
] }

或者直接给纯文本，单据之间空一行。

退出码

码含义
0已执行检查
1没给入参
3材料不足 —— 此时不给结论（既不说一致，也不说不一致）
4入参文件读不到或无法解析
9未预期错误

这个免费版不包含

以下检查项不在本版本范围内，调用时也不会执行：

  • 行内算术（数量 × 单价 = 金额）
  • 税额与价税合计自洽（不含税 + 税额 = 价税合计）
  • 发票数量 vs 入库数量的容差核对
  • 发票金额 vs 订单金额的容差核对
  • 订单数量 vs 入库数量的容差核对
  • 同一物料的单价跨单据偏离提示
  • 日期逻辑（订单 ≤ 入库 ≤ 发票）
  • 付款条款与账期字段核对

使用次数与完整档

本免费版每次运行结束后会向服务端做一次匿名次数统计：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），不发送你的材料、不写任何文件。

· 统计不可用（离线/超时/被拦截）时什么都不做，核对结果与退出码不受任何影响。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。
