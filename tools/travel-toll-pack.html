差旅与通行费技能包（免费版）

完全本地运行：引擎已经打包在本技能里（scripts/engine/）。 核对过程不需要联网、不需要 API Key、没有调用次数上限、不写任何文件，材料不出本机。

什么时候用

有大量出差的销售/工程型公司的费用会计，在每月报销审核与费用入账之前。

典型场景：月度/季度复核前，把一类检查一次跑完所有部门

这个免费版查什么

一次跑完所有部门，每家部门一行结论（免费版的核心产出，完整可用）：

  1. 差旅费标准与超标核对 —— 复用 parts/travel-standard-check/（逐字节来自免费包 travel-standard-check-free）
  2. 通行费与过路过桥核对 —— parts/toll-fee-check/（本包原生实现：上游从来没有过通行费引擎，

这一项此前误接到一个只因为 slug 里同样含 "toll" 才被选中的海关手册类工具，那个组件已整个删除）。

这一项按单据逐行核 6 个子检查：

  • 通行费金额三方勾稽（票面金额 − 折扣金额 = 折扣后金额 = 实付金额）
  • 重复通行检测（同一车牌 + 同一通行时间 + 同一实付金额）
  • 跨期检测（通行时间不在本次报销所属期间内）
  • 车辆归属核对（车牌比对随表附来的车辆台账，非公司车辆单独报出）
  • 合计行逐列复核（票面 / 折扣 / 折扣后 / 实付 各列合计 = 明细行相加）
  • 空白与占位符检测（所属期间 / 通行时间 / 车牌号 / 实付金额为空白、占位符或认不出格式）

材料要带随表附来的车辆台账（--- 车辆台账 --- 一段 + 车牌号 / 车辆归属 表头）——

没有台账就无法判断哪些通行费是非公司车辆产生的，本工具不猜，只报"材料不足"。

这一项另有 5 个子检查本免费版不执行（金额为负 / 同一票据号重复使用 / 折扣列漏填 / 车牌号格式异常 / 车辆归属与台账不一致）——它们在本免费版里没有实现， 只是在结果的 scope.sub_checks_not_run 里如实列出（--sample 输出能看到那 5 条原文）。
每一项的实际规则在 scripts/engine/parts/<检查项>/ 里：差旅费标准那一项逐字节复用免费包 travel-standard-check-free（一行规则都没有改）；通行费那一项是本包原生实现（见上面第 2 条）。 本包只做"目录 → 部门 → 逐项派发"的编排。

怎么用

node scripts/run.mjs --sample                 # 单部门样例（内置，2 项全跑）
node scripts/run.mjs --sample-batch           # 3 家部门的批量样例（干净 / 有硬伤 / 未交材料）
node scripts/run.mjs --input <部门目录>     # 批量：每个子目录 = 一家部门
node scripts/run.mjs --input <材料.json>        # 单部门：JSON 或纯文本

部门目录怎么放（每个子目录里放这家部门的一套材料，每项用 === 检查项 === 分段，Tab 分隔最稳）：

部门目录/
  豫州销售一部（2026-04 报销）/差旅材料.txt
  中岳工程二部（2026-04 报销）/差旅材料.txt

结论怎么读

  • 每家部门一行：[结论] 部门名｜问题 N 项（P0/P1/P2）｜每一项:通过 / 有问题(n) / 未执行；
  • 有价值的是问题明细：每条都带 部门 + 检查项 + 来源文件:行号 + 类别 + 具体数字；
  • 「未执行」与「通过」是两件事：没交材料 / 材料认不出表 = 未执行，不是"没问题"。

常见错法

  • 把几个部门的材料放进同一个子目录：--input 指向的目录里，每个子目录 = 一个部门。混在一起时结论里就没有部门名，跨部门台账也分不出是谁。
  • 住宿天数与出差天数不一致：标准是按天数×上限算的，两个数对不上（多住/少住）时超标校验会直接报出来。
  • 通行费材料漏了车辆台账：通行费那一段后面要跟一行 --- 车辆台账 --- 与 车牌号 / 车辆归属 表头；少了它这一项直接判"材料不足"，本工具不会替你猜哪些车牌是公司车。
  • 按票面金额报销、折扣没减：票面金额 − 折扣金额 必须等于折扣后金额，且折扣后金额必须等于实付金额 —— ETC 优惠没减下来时最先被报出来的就是这一处。
  • 同一笔通行费记了两遍：同一车牌 + 同一通行时间 + 同一实付金额 出现两次会被重复入账检测报出，合并行程时尤其容易发生。
  • 拿 --sample 的输出当自己的结论：样例数字是虚构的，必须换成你自己的材料再跑。

使用次数与完整档

本免费版每次运行结束后会向服务端做一次匿名次数统计：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），不发送你的材料、不写任何文件。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；

· 第 4 次起：服务端会返回一段完整档说明（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；

· 统计不可用（离线/超时/被拦截）时什么都不做，核对结果与退出码不受任何影响。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。
