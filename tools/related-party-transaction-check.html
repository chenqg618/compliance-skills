完全本地运行：引擎已经打包在本技能里（engine/ 目录）。 核对过程不需要联网、不需要 API Key、没有调用次数上限。

什么时候用

谁会在什么时候用：有关联方交易的企业（尤其集团与上市公司），在**年度汇算清缴填报

关联业务往来报告表、以及准备同期资料之前**。三处数字必须一致：

  • 财务账上的关联交易金额 = 台账金额 = 报告表填报金额；
  • 期末往来余额 ≥ 0；占比 = 该关联方交易金额 ÷ 营业收入；
  • 定价方法要写清、同期资料要按门槛准备。

报告表与台账对不上，是税务核查最常见的第一刀；而这些全都能算出来对错。

这个免费版查什么

  1. 合计行逐列复核（交易金额 / 台账金额 / 报告表金额 / 往来余额）；
  2. 报告表填报金额 = 台账金额（一致性，最常错的一条）；
  3. 本期交易金额 = 台账金额（账表一致）；
  4. 期末往来余额为负检测；
  5. 定价方法空白或占位符检测（关联交易必须说明定价依据）；
  6. 同一关联方同一交易类型重复行检测；
  7. 空白与占位符检测（含必需列缺失）。

常见错法（这些表里真的会有人这么填）

  1. 报告表按"含税"填、台账按"不含税"填：口径不同会让三处金额永远差一截；一张表里必须同一口径。
  2. 把往来余额当成交易金额填：交易金额是本期发生额、往来余额是时点数，混填会让占比与挂账判断全部失真。
  3. 定价方法写"市场价"：常见五法里没有这个口径，完整档会提示按五法写清（并保留同期资料支撑）。
  4. 同一关联方分两次粘贴却都写同一交易类型：会报重复行；如果确实分两笔，请合并成一行或在类型上区分。
  5. 同期资料填"无"但交易金额早已过门槛：完整档会点出来——达门槛未准备同期资料是税务检查关注点。

需要完整档时（可选）

本免费版是完整可用的核心产出，本版本不包含下面这些项：

  • 报告表金额与台账金额差异率超过 5% 提示（差异率要能解释）
  • 关联交易占营业收入比例超过 50% 提示（重大关联交易，关注特别纳税调整）
  • 期末往来余额超过本期交易金额（长期挂账）提示
  • 定价方法不在常见五法口径（可比非受控价格法/再销售价格法/成本加成法/交易净利润法/利润分割法）提示
  • 交易金额达到同期资料门槛却填「未准备/无」提示

同名工具的完整档是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别就是上面这些，没有别的。

使用次数与完整档

本免费版每次运行结束后会向服务端做一次匿名次数统计：只发送本包标识和一个不含任何材料的匿名安装标识（由主机名与用户名做短哈希得到），不发送你的材料、不写任何文件。

· 前 3 次：服务端不返回任何内容，输出与现在完全一样；

· 第 4 次起：服务端会返回一段完整档说明（完整档是另一个独立商品，条款与价格以它自己的商品页为准），届时才会打印这一行；

· 统计不可用（离线/超时/被拦截）时什么都不做，核对结果与退出码不受任何影响。

本版本不包含的检查项见上一节；需要完整档时按服务端返回的官方口令执行，付款由用户本人确认。

边界（请务必知道）

  • 不做法律与税务判断：两个主体是否构成关联关系、定价是否公允、要不要做特别纳税调整

——这些属于专业判断，请按公司法与税收口径认定；

  • 不代填关联业务往来报告表，也不出具鉴证意见与税务意见；
  • 不判断同期资料该准备哪几层（主体文档/本地文档/特殊事项文档）——本工具只核你填的字段与三处金额；
  • 不读取财务系统 / 关联交易台账系统 / 同期资料文档的原始文件——需要你先导出成文本贴进来；
  • 材料不足（认不出表头、没有数据行、必需列缺失）时不给结论，只告诉你还缺什么。
