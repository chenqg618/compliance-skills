什么时候用

谁会在什么时候用：有收银的企业每天（甚至每班）都要盘点现金 ——

应有现金 = 期初备用金 + 销售现金收入 − 现金支出；差异 = 实盘现金 − 应有现金（正=长款、负=短款）。

长短款几十块看着小，但它是收银舞弊与流程漏洞的最早信号；连锁几十上百个班次人眼核不动。

这张表会逐项核对什么：

· 应有现金 = 期初备用金 + 销售现金收入 − 现金支出

· 差异 = 实盘现金 − 应有现金；差异类型必须与差异符号一致（正=长款 / 负=短款 / 0=平）

· 合计行逐列复核（类型列是文字，不参与求和）；重复门店班次与空缺检测

每条结论都带原文行号与出处，可被第三方用同一口径复算；

材料不足时不给结论，会明确列出还缺什么。

常见错法（这张表里真的会有人这么填）

  1. 请补上这些再跑；材料不足时本工具不做任何认定，也不套用默认值。
  2. 应有现金 = 备用金 + 现金销售 − 现金支出；现金支出最容易漏记（临时采购、退款、押金）。
  3. 差异 = 实盘 − 应有；正=长款、负=短款，符号反了会把长短款说反。
  4. 差异类型必须由差异符号推出：正=长款、负=短款、0=平；类型写反会误导后续追查方向。
  5. 注意：差异类型是文字，不参与求和（合计行里应为空）。
